# トモダチアイランド

**島の住人は、ぜんぶ あなたが つくった人。**
似顔絵をつくって島に住まわせると、あとは住人たちが かってに 友達になり、けんかをし、恋をして、結婚して、子どもが生まれます。
プレイヤーは島の管理人として、ごはんをあげたり、なやみを聞いたり、恋のせわを焼いたりするだけ。

依存ライブラリなし。`tomodachi/index.html` をブラウザで開くだけで動きます（PC / タブレット / スマホ）。

```
# ローカルサーバで開く場合（リポジトリのルートで）
npx http-server -p 8080 .
# → http://localhost:8080/tomodachi/
```

このゲームは `tomodachi/` 配下で完結していて、他のゲームとはファイルを共有しません。

## 設計の背骨

| | |
| --- | --- |
| **完全ローカル** | データは 100% ブラウザの `localStorage`。サーバも共有も同期もありません |
| **育てるのは「関係」** | 数値を上げるゲームではなく、住人どうしの関係が勝手に動くのを眺めるゲーム |
| **死なない** | 放っておいても だれも いなくなりません。おなかが減って ふきげんになるだけ |
| **実時間** | 2 分で 1 こま。とじているあいだも 最大 12 時間ぶんまで 島は動いています |
| **絵はぜんぶコード** | 似顔絵は画像ファイルではなく、ベジエ曲線で毎回その場で描いています |

## 遊びかた

1. **住人をつくる** — 顔（11 項目）・性格（4 つのスライダー）・声（高さと速さ）を決めます。最大 24 人。
2. **部屋をのぞく** — 吹き出しが出ていたらタップ。なやみを聞くと まんぞくどが上がります。
3. **ごはんをあげる** — お店で買って部屋でわたす。好物なら まんぞくどが どんと上がります。
4. **レベルアップ** — まんぞくど Lv が上がるたび、インテリア・どうぐ・うた・口ぐせを 1 つプレゼント。
5. **恋のせわを焼く** — 引き合わせる／告白を後おしする／けんかを仲裁する。
6. **ミニゲーム** — こうえんで あそんで お宝とお金。お宝は しちやで 売れます。
7. **ゴール** — ねがいの ふんすいで 100 回 願いを かなえると、島ごと 宇宙ツアーへ。

## 住人

顔は 11 項目の組み合わせで作ります。

| 項目 | 種類 | 項目 | 種類 |
| --- | --- | --- | --- |
| はだの色 | 8 | かみがた | 24 |
| かみの色 | 10 | め | 20 |
| めの色 | 8 | まゆげ | 14 |
| はな | 10 | くち | 16 |
| りんかく | 10 | めがね・ひげ | 10 |
| ほお | 3 | | |

性格は 4 軸（あかるさ／うごき／はなしかた／やさしさ）で、組み合わせから 16 タイプの名前が決まります。
性格は セリフの語尾、食べ物の好み、だれと仲良くなりやすいかに ぜんぶ ひびきます。

生まれた子どもは、両親の顔パーツを半分ずつ受けついだ顔になります。

## 人間関係

```
しらない → かおみしり(10) → ともだち(35) → しんゆう(70)
                                              ↓ 相性がよく、どちらも独身なら
                                          かたおもい → こいびと → けっこん → こども
```

- 部屋が近い住人ほど 偶然出会いやすくなっています。
- しんゆう以上でも まれに けんかが起きます。放っておくと なかよし度が下がるので、仲裁してあげてください。
- 告白の成功率は なかよし度・性格の相性・まんぞくど Lv で 40〜95% のあいだで動きます。
- 結婚できるのは 恋人が しばらく続き、両方が Lv5 以上になってから。
- 親子・きょうだいは 恋愛の対象になりません。

## なやみ

21 種類。「おなかがすいた」「○○とけんかした」「○○に告白したい」「ねむれない」「かぜをひいた」「誕生日を祝ってほしい」など。
○○ には 実際の関係から選ばれた 住人の名前が入ります。

選択肢は 2〜4 個。あたりで大きく、はずれでも すこしは まんぞくどが増えます（理不尽にはしません）。

## こまかい話

- 声はブラウザの読み上げ（Web Speech API）を使います。使えない環境では静かなまま進みます。せっていで切れます。
- セーブは `localStorage` の `tomodachi-island-v1` ひとつ。せっていから まっさらに やりなおせます。
- 時間は「とじていた実時間」から追いつきます。ただし 12 時間ぶんが上限なので、1 週間ぶりに開いても 島が別世界になっていることはありません。
