# ゾンビゲート・ラン

スマホ広告でよく見る「ゲートをくぐって部隊をふやし、ゾンビの群れを撃ちたおす」タイプのランゲームです（ラストZの広告の風）。

**▶ https://otl.github.io/game1/zgate/**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。
絵も音もすべてプログラムで作っているので、画像・音声ファイルはありません。

## 遊び方

兵士の部隊は自動で前へ進みながら撃ちつづけます。プレイヤーは部隊を左右に動かすだけ。

| 操作 | タッチ／マウス | キーボード |
| --- | --- | --- |
| 左右に移動 | 画面をドラッグ | `←` `→` / `A` `D` |
| 一時停止 | 右上の II | `P` / `Esc` |
| 音のオン／オフ | 右上の ♪ | `M` |

- **青いゲート**（`+10` `×2` など）をくぐると仲間がふえる。**赤いゲート**（`−6` `÷2`）はへる
- 照準マークのついた赤いゲートは、撃つと数字がふえて青くなる。すぐもらえる小さいゲートと、撃ってそだてるゲートのどちらをとるか
- ゾンビにぶつかると、ゾンビ 1 体につき兵士が 1 人へる。大きいゾンビは 6 人へらす。走るゾンビは部隊を追いかけてくる
- **木箱**は撃ってこわすとごほうび。🔫 は武器がつよくなる（ピストル → ライフル → マシンガン → ミニガン → レーザー）、`+N` は仲間がふえる。こわさずにぶつかると兵士がへる
- さいごは**巨大ゾンビのボス**。うでをふり上げると足もとが赤く光るので、横にはなれてたたきつけをかわす。ボスは手下もよぶ
- 兵士がいなくなると全滅

## コインときょうか

たおしたゾンビ・ボス・のこった兵士の数でコインがもらえます。タイトル画面できょうかできます。

| きょうか | 内容 |
| --- | --- |
| 初期兵士 | はじめの兵士が 1 人ずつふえる |
| 攻撃力 | ダメージが 12% ずつ上がる |
| 初期武器 | ライフル／マシンガンからスタート |
| コイン報酬 | もらえるコインが 10% ずつふえる |

ステージが進むほどゾンビとボスがかたくなり、ゲートの数字も大きくなります。
進みぐあいとコインはブラウザ（localStorage）に保存されます。
