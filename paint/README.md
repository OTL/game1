# おえかきスタジオ

アイビスペイントのように**自由に絵が描ける**お絵かきツール＋お題チャレンジ。
依存ライブラリなし。`paint/index.html` をブラウザで開くだけで動きます（PC / スマホ両対応）。

```
# ローカルサーバで開く場合（リポジトリのルートで）
npx http-server -p 8080 .
# → http://localhost:8080/paint/
```

このゲームは `paint/` 配下で完結しており、リポジトリ直下の他のゲームとはファイルを共有しません。

## 描きかた

キャンバスをなぞるだけで描けます。ペンタブや Apple Pencil の**筆圧**に対応していて、
筆圧が取れない環境（マウス・指）では**描く速さ**で線の太さが変わります。

| 操作 | PC | スマホ / タブレット |
| --- | --- | --- |
| 描く | ドラッグ | 指・ペンでなぞる |
| 拡大・縮小 | ホイール、＋ / − ボタン | 2 本指ピンチ |
| 画面を動かす | 右ドラッグ / 中ドラッグ / Space+ドラッグ / ✋移動ツール | 2 本指ドラッグ、✋移動ツール |
| 全体表示に戻す | 上部の ⤢ | 上部の ⤢ |

## 道具

| ツール | 特徴 |
| --- | --- |
| 🖊️ ペン | 輪郭のはっきりした線。線画向き |
| 🖌️ 筆 | 筆圧・速度で太さが大きく変わる。塗りにも使える |
| ✏️ 鉛筆 | ざらつきのある粒状の線 |
| 🖍️ マーカー | **乗算**で重なる蛍光ペン。重ねるほど濃くなる |
| 💨 エアブラシ | ふんわり吹きつける。影やグラデーション向き |
| 🧽 消しゴム | レイヤーの内容を消す（背景は消えません） |
| 🪣 塗りつぶし | 見えている絵から領域を判定し、選択中のレイヤーに色を置く。許容値で調整 |
| 💧 スポイト | 画面の色を拾ってブラシの色にする |
| ✋ 移動 | キャンバスをドラッグで動かす |

ブラシごとに太さと不透明度を個別に記憶するので、ツールを行き来しても設定が戻りません。

## 特徴

- **手ブレ補正**（0〜10）… 上げるほど線がなめらかになります
- **対称定規**（左右 / 上下 / 4分割）… 左右対称の絵やマンダラ模様が一気に描けます
- **レイヤー**（最大 12 枚）… 表示切替・不透明度・並べ替え・複製・下と結合
- **半透明のブラシがきれいに出る**… 1 ストロークをいったん別バッファに描いてからまとめて転写するので、同じ場所を往復しても濃くなりません
- **元に戻す / やり直す** 50 手ぶん（線だけでなくレイヤー操作も対象）
- **自動保存**… 描いている絵はブラウザに保存され、次に開くと続きから描けます
- **PNG 書き出し**… 背景色ごと 1 枚の画像として保存

## 🎯 お題チャレンジ（ゲームモード）

ランダムなお題を制限時間内（1 分 / 3 分 / 10 分 / 無制限）に描ききるモードです。
時間内に「できた！」を押すとボーナス。終了すると採点結果が出ます。

採点は絵のうまさではなく、**数えられるもの**だけを見ています。

| 項目 | 満点 | 見ているもの |
| --- | --- | --- |
| 描き込み | 30 | 引いた線の数 |
| 色づかい | 20 | 使った色の数 |
| 画面の使いかた | 30 | キャンバスを塗った面積 |
| レイヤー活用 | 10 | 使ったレイヤーの枚数 |
| 時間の使いかた | 10 | 制限時間をどれだけ使ったか（早く完成でボーナス） |

合計点で S / A / B / C / D のランクがつき、気に入った作品は**ギャラリー**（ブラウザ内に最大 12 作品）に残せます。

## ショートカット

`B` ペン / `N` 筆 / `P` 鉛筆 / `M` マーカー / `A` エアブラシ / `E` 消しゴム / `G` 塗りつぶし / `I` スポイト / `H` 移動
`[` `]` 太さ変更 / `Ctrl+Z` 元に戻す / `Ctrl+Shift+Z` やり直す / `Ctrl+S` PNG 保存 / `Space+ドラッグ` 画面移動

## ファイル構成

```
paint/
├── index.html
├── css/style.css
└── js/
    ├── color.js      … 色の変換（HSV ⇔ RGB ⇔ HEX）
    ├── brushes.js    … ブラシ定義とスタンプ描画（スプライトのキャッシュ）
    ├── engine.js     … レイヤー・ストローク・履歴・表示変形・書き出し
    ├── challenge.js  … お題・タイマー・採点・ギャラリー保存
    └── ui.js         … ツール / 色 / レイヤー UI と入力（ポインタ・ピンチ・キー）
```

保存に使う localStorage のキーは `game1.paint.session`（描きかけの絵）、
`game1.paint.gallery`（ギャラリー）、`game1.paint.recent`（最近使った色）です。
