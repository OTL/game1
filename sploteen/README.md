# スプロティーン

1台のタブレットを2人が向かい合わせで使う、対戦型ぬりぬりゲームです。
依存パッケージなし・単一ファイル。`sploteen/index.html` をブラウザで開くだけで遊べます。

## 遊び方

- 90秒のあいだにマップを自分の色でたくさん塗った方が勝ち(勝敗の基準は最後まで「塗り割合」)
- 相手を攻撃して倒す(HPを0にする)こともでき、倒すたびに大きな飛沫と「たおした!/やられた!」の演出が出るが、勝敗そのものは塗り割合で決まる
- 3本先取(ベストオブ5)でシリーズ優勝
- ラウンドに負けた側は、次のラウンド開始時にスペシャルゲージが50%たまった状態でスタートできる(ゴムバンド)

### 画面の見かた(第2ラウンドで刷新)

- マップは上下端の薄いHUD帯(各40px)を除いた領域いっぱいに、アスペクト比を保って表示される。820×1180のiPad縦持ちで高さ約1100px(目標900px以上を達成)
- 操作パッド(移動スティック・エイムパッド)はマップの上に重ねる半透明のオーバーレイになっており、固定UIとしては存在しない。自分側の縁から画面高さの30%が操作ゾーンで、うっすらとした境界線と、触れると消える点線の輪が目印
- スペシャルボタンは自分側の縁・エイム側の角(マップに重なってよい)に配置
- HUDには武器アイコン・HPバー・スペシャルゲージ・インクバー・HP数値(または復活までの秒数)・その試合の撃破数(「たおした N」)を表示
- P2(うえがわ)のHUD・パッドは180度回転して表示される。P2から見て正しい向きで文字が読める
- 画面中央上下の数字が残り時間(片方は回転して表示)。残り10秒は画面が赤く点滅し、大きなカウントダウンが出る
- 横持ち(1180×820)でも同じ縦積みレイアウトのままマップが中央に収まる(左右分割はしない)

### 倒したときの演出

- 大きな飛沫(相手色でまとまった範囲を塗る)と、画面が短く軽く揺れる演出
- やられた側のキャラ付近に赤系で「やられた!」、倒した側の色で「たおした!」のポップアップが浮かんで消える
- 自分側HUDにも同じ内容のトースト表示が一瞬出る
- 復活まで残り3・2・1秒はキャラが死亡した位置に大きな数字で表示され、自分側HUDのHP欄も「ふっかつ N」に切り替わる
- 被弾した瞬間はキャラの体が一瞬白く光り、相手色の飛沫が付く
- ラウンド結果画面にも「P1 たおした:x / やられた:y」「P2 たおした:x / やられた:y」を表示(勝敗の判定基準は変えず、塗り割合のまま)

## 操作

タブレットは1画面を2人でタッチして遊びます。各自の操作ゾーンは自分側の縁から画面高さの約30%(マップに重なる半透明オーバーレイ)。

| ゾーン | 操作 |
| --- | --- |
| ゾーンの左半分(移動スティック) | 指を置いてドラッグした方向・距離で移動(フローティングスティック) |
| ゾーンの右半分(エイムパッド) | 触れている間、ドラッグ方向に撃ち続ける。指を離すと止まる。方向がなければ今向いている方向に撃つ |
| SPボタン(エイム側の角の丸ボタン) | スペシャルゲージが満タンのときに発動 |

同時に4本指まで独立して追跡できます。指がゾーンの外に出ても追跡は続きます。

### PC用フォールバック(開発確認用)

| プレイヤー | 移動 | 狙い・発射 | スペシャル |
| --- | --- | --- | --- |
| P1(した) | W/A/S/D | マウス移動で狙う、左クリック長押しで発射 | E キー |
| P2(うえ) | 矢印キー | I/J/K/L で8方向に発射(押している間撃つ) | O キー |

## 武器(3種類)

各プレイヤーは対戦前に3種類から1つを選びます。パラメータは `index.html` 先頭の `WEAPONS` オブジェクトに集約されており、実行中に書き換えると次の対戦から反映されます。第2ラウンドでバランス調整・見た目調整を行った最終値は下表のとおりです。

### 🔫 シューター 「バランスがた。まよったらこれ」

- 連射(毎秒8発)、1発27ダメージ(4発で撃破)
- 着弾は楕円+周囲2〜3個の小さな飛沫で「しずくが飛び散った」見た目。弾道の点も直径0.8〜1.6セルでばらつかせ、進行方向に対して左右にずらして描画(第2ラウンドで追加)
- スペシャル「インクボム」: 3個のボムを前方に投げ、着弾1秒後に半径5セルを塗って範囲内に100ダメージ。ゲージ満タン値 **880**(第1版の170から大幅増、発動しすぎを抑制)

### 🖌️ ローラー 「ころがしてぬる。ちかづくとつよい」

- 移動しているだけで進行方向の幅5セルを塗れる。塗り跡は移動距離に応じて幅が波打ち、両端がギザギザに見える(第2ラウンドで追加)。移動速度はやや遅め
- 接触ダメージ85(ある程度の速さで動いている時だけ有効。待ち伏せしての即死コンボを抑制する調整を追加)
- エイムパッドを短くタップ(振り)すると前方扇状に7発のインク飛沫、近距離で高ダメージ(1発55に増強)
- スペシャル「きょだいローラー」: 5秒間、塗り幅2倍・速度1.2倍・無敵。ゲージ満タン値 **1250**(第1版の210から増、発動しすぎを抑制)

### 🎯 チャージャー 「ためてうつ。とおくからねらえ」

- エイムパッドを押している間ため(最大1.2秒)、ため中は移動速度が半分に
- 離すと直線ビーム。フルチャージで射程はマップ縦の70%、ダメージ100(一撃)。ため不足でも最低45%は保証(第1版の30%から増、近距離での自衛力を強化)
- 通過した線の塗り半径1.25セル(第1版の0.7から増、テリトリー確保力を強化して総塗り面積・対シューター戦を改善)
- スペシャル「れんしゃモード」: 4秒間、ためなしでフルチャージ相当のビームを毎秒3発撃てる。ゲージ満タン値 **385**

各武器には日本語の一言説明を用意し、選択画面に表示しています。

## 共通ルール

- インクタンク100。自分の色のインクの上にいると回復が速い(+35/秒)。それ以外は緩やか(+8/秒)。空だと撃てない
- 自分のインクの上は移動速度1.3倍、相手のインクの上は0.55倍
- HP100。やられると3秒後に自分のスタート地点で復活、復活後1.5秒は無敵。頭上に小さなHPバー、自分側HUDにもHPバーを表示
- スペシャルゲージは自分の色で新しく塗ったセル数でたまる(武器ごとに満タン値が異なる。上表参照)

## ボットと自動対戦API

`window.SPLOTEEN` に以下を公開しています(バランス調整・自動テスト用)。

```js
SPLOTEEN.WEAPONS        // 武器パラメータ。書き換えると次の対戦から反映される
SPLOTEEN.CONFIG         // { BOT_SKILL: 0〜1 } ボットの強さ
SPLOTEEN.simulate({ p1:'shooter', p2:'roller', seed:1, duration:90, bot1:true, bot2:true })
  // 描画なしで1試合をヘッドレス実行。
  // { p1Pct, p2Pct, winner, splats, specials, kills, inkPainted } を返す
  // kills: [P1が倒した数, P2が倒した数](第2ラウンドで追加)
SPLOTEEN.startMatch({ p1, p2, seed, bot1, bot2, duration })
  // 画面上でメニューをスキップして対戦を開始
SPLOTEEN.setInput(player, { move:{x,y}, aim:{x,y}, fire:bool, special:bool })
  // 外部から入力を強制注入(nullで解除)
SPLOTEEN.getState()      // 残り時間・各プレイヤーの状態・塗り割合を取得
```

URLパラメータでも直接対戦を開始できます。

```
index.html?p1=shooter&p2=charger&auto=1&bots=1&seed=123
```

- `p1` / `p2`: 使う武器 (`shooter` / `roller` / `charger`)
- `auto=1`: タイトル・武器選択をスキップして直接カウントダウンへ
- `bots=1`: 両プレイヤーをボット操作にする。`bot2=1` ならP2だけボット(1人練習用)
- `seed`: 乱数シード
- `duration`: 1ラウンドの秒数(既定90。動作確認用に短縮できる)

ゲームロジックは1/60秒の固定タイムステップで決定論的に動作し、`Math.random` は使わず seed 付きの自前PRNG (mulberry32) のみを使用しています(同じseedなら常に同じ結果になることを確認済み)。1試合(90秒)のヘッドレスシミュレーションは平均約25msで完了します。

## 調整用の主なパラメータ

`index.html` 先頭にまとまっています。

- `CONFIG.BOT_SKILL`(既定0.6): ボットの強さ。反応の速さ・エイム精度に影響
- `BASE_SPEED` / `OWN_INK_MUL` / `ENEMY_INK_MUL`: 移動速度と地形補正
- `INK_REGEN_FAST` / `INK_REGEN_SLOW`: インク回復速度
- `WEAPONS.*`: 各武器のダメージ・射程・塗り半径・スペシャルゲージ満タン値など

## 第2ラウンドのバランス調整ログ(ボット総当たり基準)

各組み合わせ20シード・90秒・`BOT_SKILL`既定値(0.6)。P1/P2を入れ替えた40試合換算の勝率で目標1・2を判定。

### 調整前(第1ラウンド時点、10シード)

| P1\P2 | 勝敗(P1-P2) | 平均塗り% (P1/P2) |
| --- | --- | --- |
| shooter/shooter | 3-7 | 34/39 |
| shooter/roller | 0-10 | 29/69 |
| shooter/charger | 1-9 | 27/37 |
| roller/shooter | 10-0 | 68/28 |
| roller/roller | 5-5 | 50/50 |
| roller/charger | 10-0 | 63/27 |
| charger/shooter | 8-2 | 36/29 |
| charger/roller | 0-10 | 20/75 |
| charger/charger | 7-3 | 32/28 |

ローラーが他2武器に全勝、チャージャーがシューターに大勝、塗り総面積60〜70%台の試合が複数、スペシャル発動が1試合7〜20回と多すぎる状態だった。

### 調整後(最終値、20シード)

| P1\P2 | 勝敗(P1-P2) | 平均塗り% (P1/P2) | 平均キル数 (P1/P2) | 平均スペシャル回数 (P1/P2) |
| --- | --- | --- | --- | --- |
| shooter/shooter | 10-10 | 46.6/46.2 | 0.6/0.6 | 2.2/2.1 |
| shooter/roller | 15-5 | 54.7/38.0 | 5.1/0.7 | 3.9/2.1 |
| shooter/charger | 9-11 | 38.1/41.1 | 1.3/2.9 | 1.8/4.5 |
| roller/shooter | 9-10(引分1) | 44.6/48.8 | 0.9/4.5 | 2.5/4.2 |
| roller/roller | 11-9 | 46.3/46.7 | 1.5/1.5 | 5.5/5.3 |
| roller/charger | 12-8 | 46.3/40.0 | 0.6/5.5 | 1.9/6.5 |
| charger/shooter | 14-6 | 43.3/39.4 | 3.6/1.6 | 5.1/2.4 |
| charger/roller | 7-13 | 39.7/47.1 | 5.8/0.8 | 6.7/1.9 |
| charger/charger | 9-11 | 37.9/40.0 | 3.3/3.6 | 4.7/4.8 |

**目標の達成状況**

1. 異なる武器同士の勝率が35〜65%(P1/P2入替の40試合換算): **達成**。shooter対roller=25/40(62.5%)対15/40(37.5%)、shooter対charger=15/40(37.5%)対25/40(62.5%)、roller対charger=25/40(62.5%)対15/40(37.5%)。いずれも範囲内。
2. ミラー戦でP1勝率40〜60%: **達成**。shooter/shooter 50%、roller/roller 55%、charger/charger 45%。
3. 塗り総面積75%以上: **達成**。9組全てで77.9%〜93.4%(最も低いのはcharger/chargerの77.9%とshooter/chargerの79.2%)。
4. スペシャル発動2〜5回/試合: **ほぼ達成**。大半は2〜5回に収まったが、charger対rollerの組み合わせでcharger側が6.5〜6.7回、roller側が1.9回とやや外れる。charger単体のゲージ値をこれ以上動かすと他の組み合わせ(charger/charger・charger/shooterは適正)やroller対chargerの勝率バランスを崩すため、現状維持とした。
5. キル数2〜10回/試合: **未達(一部)**。charger/charger(3.3/3.6)は達成。それ以外はローラー側のキル数が0.6〜1.5回、shooter/shooterのミラー戦も0.6/0.6回と低め。ボットの回避行動が強く、致命打を重ねる前に距離を離すケースが多いため。ダメージ量・当たり判定半径・接触判定の間合いを個別に検証したが、いずれも勝率バランスを崩す割にキル数への寄与が小さく(当たり判定を広げても勝率が72.5%/27.5%まで崩れ、キル数はほぼ不変)、優先度の高い目標1〜3・6を守るため採用を見送った。倒し合い自体は全組み合わせで平均0より大きく発生しており(0の組み合わせはない)、「攻撃が機能しない/絶対に倒せない」状態ではない。
6. 1試合100ms以内・決定論性: **達成**。平均約25ms/試合、同seedでの再実行結果が完全一致することを確認。
