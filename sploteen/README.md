# スプロティーン

1台のタブレットを2人が向かい合わせで使う、対戦型ぬりぬりゲームです。
依存パッケージなし・単一ファイル。`sploteen/index.html` をブラウザで開くだけで遊べます。

## 遊び方

1. タイトル画面で「ふたりで たいせん」(通常の2人対戦)か「ひとりで れんしゅう (CPU)」(1人でCPU相手に練習)を選ぶ
2. 武器選択画面で、各プレイヤーがメイン武器(5種類)・サブウェポン(4種類)・スペシャル(3種類)をそれぞれ1つずつ選ぶ。画面上部の「アバター」ボタンから自分のキャラも作れる
3. 「じゅんび OK」を両者(CPUモードでは自分だけ)が押すとカウントダウンの後、1ラウンド90秒の対戦が始まる
4. 90秒のあいだにマップを自分の色でたくさん塗った方がそのラウンドの勝ち(勝敗の基準は最後まで「塗り割合」)
5. 相手を攻撃して倒す(HPを0にする)こともでき、倒すたびに大きな飛沫と「たおした!/やられた!」の演出が出るが、ラウンドの勝敗そのものは塗り割合で決まる
6. **3ラウンド制・2本先取**でシリーズ優勝が決まる(1ラウンド目を落としても2ラウンド目・3ラウンド目で挽回できる)
7. ラウンドに負けた側は、次のラウンド開始時にスペシャルゲージが50%たまった状態でスタートできる(ゴムバンド調整)

### ひとりで れんしゅう (CPUモード)

- タイトルで「ひとりで れんしゅう (CPU)」を選ぶと、P2(うえ)がCPU操作になる
- 武器選択画面のP1(した)側に「CPU(うえ)の ぶきを えらぶ」という武器・サブ・スペシャルの3行と「CPU の つよさ」ボタン(よわい/ふつう/つよい)が出る。P1は自分の側からCPUの装備・強さの両方を選べる(P2側の回転表示にもそのままCPUの選択が反映される)
- 強さは `CONFIG.BOT_SKILL` に反映される: よわい=0.35 / ふつう=0.6 / つよい=0.85
- CPU側の「じゅんび」は自動でON扱いになり、P1が「じゅんび OK」を押すだけで対戦が始まる
- 既存のURLパラメータ `bot2=1` / `bots=1` はメニューを通しても引き続き有効(タイトルで「ふたりで たいせん」を選んでも、URLで指定した側はCPU操作になる)

### 画面の見かた

- マップは上下端の薄いHUD帯(各48px)を除いた領域いっぱいに、アスペクト比を保って表示される
- 操作パッド(移動スティック・エイムパッド)はマップの上に重ねる半透明のオーバーレイになっており、固定UIとしては存在しない。自分側の縁から画面高さの30%が操作ゾーンで、うっすらとした境界線と、触れると消える点線の輪が目印
- スペシャルボタン(SP)は自分側の縁・エイム側の角に配置。サブボタンはその隣に同じ大きさで配置され、クールダウン中・インク不足のときは暗く表示される
- HUDには武器アイコン・HPバー・スペシャルゲージ・インクバー・HP数値(または復活までの秒数)・その試合の撃破数(「たおした N」)を表示
- P2(うえがわ)のHUD・パッドは180度回転して表示され、P2から見て正しい向きで文字が読める
- 画面中央上下の数字が残り時間(片方は回転して表示)。残り10秒は画面が赤く点滅し、大きなカウントダウンが出る
- 横持ちでも同じ縦積みレイアウトのままマップが中央に収まる(左右分割はしない)。武器選択画面だけは横持ち時にメイン/サブ/スペシャル/CPUパネルを横並びに組み替え、縦スペースを節約する

### リセットボタン(第7ラウンドで追加)

- 画面左端の中央(上下のHUD帯の間、操作パッドの帯からは離れた位置)に直径40px程度の半透明の丸い「↺」ボタンを常設。誤タップしにくいよう半透明・パッド帯の外に配置している
- タイトル画面では非表示。武器選択・カウントダウン・対戦中・ラウンド結果・優勝画面では表示される
- タップすると確認オーバーレイ「さいしょから やりなおす?」が開く。文言はP1向き(下)・P2向き(上、180度回転)の両方に表示し、「はい」「いいえ」ボタンは中央共通(どちらのプレイヤーが押してもよい)
- 「はい」: 進行中のシリーズを中断し、スコア・ラウンド数・塗りをすべて初期化してタイトル(ふたりで たいせん / ひとりで れんしゅう の選択)へ戻る
- 「いいえ」: オーバーレイを閉じて続行(ゲーム状態は変化しない)
- `simulate()` によるヘッドレス対戦には一切関与しない(画面のボタン・オーバーレイのみの機能)

### 倒したときの演出

- 大きな飛沫(相手色でまとまった範囲を塗る)と、画面が短く軽く揺れる演出
- やられた側のキャラ付近に赤系で「やられた!」、倒した側の色で「たおした!」のポップアップが浮かんで消える。自分側HUDにも同じ内容のトーストが一瞬出る
- 復活まで残り3・2・1秒はキャラが死亡した位置に大きな数字で表示され、自分側HUDのHP欄も「ふっかつ N」に切り替わる
- 被弾した瞬間はキャラの体が一瞬白く光り、相手色の飛沫が付く
- ラウンド結果画面には塗り割合の他に「P1 たおした:x / やられた:y」「P2 たおした:x / やられた:y」も表示される(勝敗の判定基準は変えず、塗り割合のまま)

## 操作(ツインスティック)

タブレットは1画面を2人でタッチして遊びます。各自の操作ゾーンは自分側の縁から画面高さの約30%(マップに重なる半透明オーバーレイ)。

| ゾーン | 操作 |
| --- | --- |
| ゾーンの左半分(移動スティック) | 指を置いてドラッグした方向・距離で移動(フローティングスティック) |
| ゾーンの右半分(エイムパッド) | 触れている間、ドラッグ方向に武器を撃ち続ける(チャージャーはため続ける)。指を離すと止まる。方向がなければ今向いている方向に撃つ |
| SPボタン(エイム側の角の丸ボタン) | スペシャルゲージが満タンのときに発動 |
| サブボタン(SPボタンの隣) | タップでサブウェポンを使用(インクを消費、使用後1.0秒クールダウン)。投げる/設置する向きは最後にエイムした方向(なければ移動方向) |

同時に4本指まで独立して追跡できます。指がゾーンの外に出ても追跡は続きます。

### PC用フォールバック(開発確認用)

| プレイヤー | 移動 | 狙い・発射 | スペシャル | サブ |
| --- | --- | --- | --- | --- |
| P1(した) | W/A/S/D | マウス移動で狙う、左クリック長押しで発射 | E キー | R キー |
| P2(うえ) | 矢印キー | I/J/K/L で8方向に発射(押している間撃つ) | O キー | U キー |

## メイン武器(5種類)

各プレイヤーは対戦前に5種類から1つを選びます。パラメータは `index.html` 先頭の `WEAPONS` オブジェクトに集約されており、実行中に書き換えると次の対戦から反映されます。値の「(人間)」はプレイヤー操作専用のインクコスト(下記「インクのルール」参照)、それ以外はCPU・人間共通です。

### 🔫 シューター「バランスがた。まよったらこれ」

- 連射(毎秒8発)、1発35ダメージ(3発で撃破)、射程280px(マップ幅672pxの4割程度)の近距離武器
- 移動速度は他武器よりやや速い(`moveSpeedMul=1.14`)
- 着弾の塗り半径2.05セル。1発の消費インクは6(人間は2)
- 既定サブ: スプラッシュボム / 既定スペシャル: せんせいストライク

### 🖌️ ローラー「おもくて おそい。ボタンを おしながら ころがして ぬる。ひいて たおす」

- 移動速度は全武器で最も遅い(`moveSpeedMul=0.78`)。相手インクの上ではさらに大きく減速する(`enemyInkMul=0.44`)
- **転がしモード(第7ラウンドで変更)**: エイムパッド(fire入力)を押している間だけ「転がしモード」になり、押しながら基準速度の30%以上(`ROLL_PAINT_MIN_SPEED_MUL=0.3`)で動いている間だけ進行方向の幅5セルを塗れる(`rollWidth=5`)。塗り跡は移動距離に応じて幅が波打ち、両端がギザギザに見える。**エイムパッドを押していない時や、押していても止まっている時は塗らない**(ずっと自機の周りを塗り続けることはできない)。転がしモード中はキャラの前に短いローラーの棒を表示し、離すと消える
- **転がしのインク消費(第8ラウンドで変更)**: 人間プレイヤーの転がしは「転がして進んだ距離(1pxにつき`rollCostPerPx=0.045`)」+「新しく塗ったセル数(1セルにつき`rollCostPerCell=0.05`)」を消費する。距離の分があるので自陣の色の上を転がしていてもタンクは減り、転がしている間は回復も止まる(消費のたびに`INK_REGEN_DELAY`の待ち時間がリセットされる)。押しっぱなしで転がし続けると満タンから約10秒で空になり、エイムパッドを離して0.5秒待つと地形に応じた回復が始まる。インクが0になると転がしても塗れない
- 接触ダメージ60。転がしモード中(押しながら、基準速度の50%以上で動いている時)だけ接触キルが発動する(待ち伏せしての即死コンボ・待機中の轢き逃げを防止)
- エイムパッドを短くタップ(押してから`TAP_MAX_DURATION`(既定0.25秒)未満で離す=振り)すると前方扇状に7発のインク飛沫、1発55ダメージ。それより長く押した場合は転がしモードのままになり、離しても振りは出ない。振りの消費インクは34(人間は20)
- PC用フォールバックでも同じ理屈: P1はマウス左ボタン長押し、P2はIJKL長押しが転がしモードの入力になる(短く離せば振り)
- CPU(ボット)は、塗るために移動する間はfireを押し続けて転がしモードを維持し、振りの間合いに入った時だけ一瞬離してから短くタップし直して振りを出す(判断ロジック自体は変えず、fire入力の出し方だけ読み替えている)
- 既定サブ: クイックボム / 既定スペシャル: マンタりんぶ

### 🎯 チャージャー「ためてうつ。とおくからねらえ」

- エイムパッドを押している間ため(最大1.2秒)、ため中は移動速度が半分に
- 離すと直線ビーム。フルチャージで射程はマップ縦の70%、ダメージ100(一撃)。ため不足でも最低45%は保証
- 通過した線の塗り半径1.4セル
- 消費インクは基礎15+チャージ割合×35(人間は基礎6+チャージ割合×12)。ため始めるにはインクが8以上必要
- 既定サブ: スプリンクラー / 既定スペシャル: せんせいストライク

### 🪣 バケツ「ひろく ぬる。かべを こえて とどく」

- エイムパッドを触れている間、0.48秒ごとに1発。前方に扇状(半角20度、射程230px)の大きなかたまりを塗る。**壁を無視して届く**(壁越しに塗り・攻撃ができる唯一の武器)
- 近距離(8セル以内)の敵に70ダメージ。1発の消費インクは19(人間は8)
- 移動速度はやや速め(`moveSpeedMul=1.06`)
- 既定サブ: スプラッシュシールド / 既定スペシャル: むらさめウツボ

### 🖌 フデ「かるくて はやい。れんぞくで ふりはらう」

- 移動速度は全武器最速(`moveSpeedMul=1.45`)。相手インクの上での減速は他武器より緩やか(`enemyInkMul=0.75`)
- 移動しているだけで幅2セルを塗れる(`trailWidth=2.0`。接触ダメージなし)。ローラー(幅5セル・接触キル)との違いは「速いが倒せない/倒されにくい」対「遅いが轢ける」
- エイムパッドを押している間0.22秒ごとに自動連続で振りはらい、1発10ダメージ×4発、射程150px。1振りの消費インクは6
- 既定サブ: クイックボム / 既定スペシャル: マンタりんぶ

各武器には日本語の一言説明を用意し、選択画面に表示しています。

## サブウェポン(4種類)

メインとは別に、対戦前にサブウェポンを1つ選びます。使用にはインクが必要で、足りないとサブボタンが暗くなって使えません。使用後は共通で1.0秒のクールダウンがあります。投げる/設置する向きは「最後にエイムした方向(なければ移動方向)」で、飛距離は固定です。パラメータは `index.html` の `SUBS` オブジェクトに集約されています。

| サブ | 絵文字 | 説明 | 主なパラメータ |
| --- | --- | --- | --- |
| スプラッシュボム | 💣 | なげて じばくはつ。ひろく ぬれる | 飛距離200px、着地1.0秒後に爆発、半径4.5セル、中心100/端40ダメージ、インク45 |
| クイックボム | ⚡ | あたると すぐ ばくはつ。れんとうできる | 飛距離160px、着弾で即爆発、半径2.5セル、中心35/端15ダメージ、インク28 |
| スプリンクラー | 🌀 | おいとくと じどうで ぬってくれる | 飛距離150px、設置後8秒間、周囲半径5セルにランダムに飛沫を撒いて塗る(ダメージなし)。同時に1個まで、相手の弾で壊せる(HP30)。インク40 |
| スプラッシュシールド | 🛡 | かべを つくって まもる | 前方3セルに幅6セルのインクの壁を5秒間設置。相手の弾・ビームを止める(自分の弾は通る)。相手は壁を通れないが、自分は通れる。壁の下は自分色に塗られる。インク50 |

- 既定サブ: 選択画面の初期値はP1がシューター+スプラッシュボム、P2がローラー+クイックボムで、CPU/自動対戦の既定サブは武器ごとに shooter→splashbomb / roller→quickbomb / charger→sprinkler / bucket→shield / brush→quickbomb(`WEAPONS[key].defaultSub`)
- サブウェポンの使用回数は `stats.subsUsed` に記録され、`simulate()` の戻り値 `subs:[n1,n2]` で取得できる

## スペシャル(3種類)

武器から独立した必殺技です。武器選択画面3行目の「スペシャル」で、メイン・サブとは別に1つ選びます。ゲージは全武器共通の `SPECIAL_GAUGE_MAX`(既定1800)で統一されており、自分の色で「新しく塗ったセル数」だけたまります(塗り直しは加算しない)。倒すと `SPECIAL_KILL_BONUS`(ゲージ比15%)ぶん追加でたまります。パラメータは `index.html` の `SPECIALS` オブジェクトに集約されています。

### ⚡ せんせいストライク

まっすぐ とおくまで こうげき。よけられても こおらせる。

- 発動から0.6秒の予告時間(赤い細い線でキャラの向いている方向を予告)ののち、その方向へマップ端まで届く幅5セルの一撃を放つ
- 直撃した敵は100ダメージ(ほぼ即倒し)。直撃を免れても、範囲の縁(直撃の外側+3セル、幅11セル相当)にいれば「こおり」状態になる
- 発動中もキャラは自由に動ける

### 🐍 むらさめウツボ

まえの ひろい はんいに ウツボの ぐんれいが ふりそそぐ。

- 発動から5秒間、キャラの前方・幅12セル×奥行き16セルの範囲にウツボの群れが降り注ぐ(範囲はキャラの向きに追従)
- 範囲を毎秒40%ずつ塗りつぶし、範囲内の敵に毎秒35ダメージ。当たった敵は「はっこう」状態になる
- 発動中も自分は自由に動ける

### 🪁 マンタりんぶ

むてきで マンタに のり、たいあたり と インクだんで あばれる。

- 発動から3秒間マンタに乗る。**無敵**・移動速度×1.3・幅6セルの跡を塗る
- 体当たり(接触)で敵に85ダメージ。半径6セル以内の敵を毎秒少しずつ引き寄せる
- エイムパッドで大きなインク弾(半径3セル塗り、42ダメージ、毎秒2発)を投げられる
- 接触・インク弾どちらで当てても「あぶり」状態を付与する

### 状態異常

| 状態 | 付与する特殊 | 効果 |
| --- | --- | --- |
| こおり ❄️ | せんせいストライク(縁の範囲) | 2秒間動けない(撃つことはできる) |
| はっこう 🫧 | むらさめウツボ | 4秒間、移動速度×0.6・被ダメージ×1.5 |
| あぶり 🔥 | マンタりんぶ(接触/インク弾) | 3秒間、毎秒12ダメージ |

「こおり」「はっこう」「あぶり」はキャラの頭上に小さなアイコンと残り時間のリングで表示されます。復活すると状態異常はすべて解除されます。`simulate()` の戻り値 `statusHits:[n1,n2]` で、各プレイヤーが状態異常を新規に与えた回数を取得できます。

## インクのルール

インクタンクは共通で100。地形の上にいると移動速度が変わります(自分の色の上は1.3倍、相手の色の上は0.55倍。ローラーは相手色の上でさらに重く感じる0.44倍、フデは逆に軽い0.75倍)。

### 人間プレイヤー(タッチ操作)のインク経済

CPUとの差別化として、人間が操作するプレイヤーには次の専用ルールが適用されます(CPUには一切適用されません)。

- 地形によるインク回復速度: **自陣の色の上+35/秒・未塗りの上+8/秒・相手の色の上+0/秒**
- 撃つ・振る・ため中・サブを使う、いずれの消費でも「最後にインクを消費してから **0.5秒**(`INK_REGEN_DELAY`)」は回復が始まらない
- 武器ごとの人間専用インクコスト: シューター1発2 / ローラー振り20 / チャージャー基礎6+チャージ割合×12 / バケツ1発8
- ローラー・フデは「移動しているだけで塗れてインクを一切使わない」性質があるため、両武器の移動塗りには専用コストがあります
  - ローラーの転がし(第8ラウンドで変更): 進んだ距離1pxにつき0.045(`rollCostPerPx`)+ 新しく塗ったセル1つにつき0.05(`rollCostPerCell`)。この消費は0.5秒の回復待ちをリセットするので、**転がしている間はインクが回復しない**(自陣の上でも減る)。転がしっぱなしで満タンから約10秒
  - フデの走り塗り: 新しく塗ったセル1つにつき0.06(`brushCostPerCell`。自陣の上を通っても新規扱いにならず無料)。この消費は0.5秒の回復待ちをリセットしないので、自陣インクの上を走っている間は消費と同時に回復も進みます

### CPU(ボット)のインク経済

CPUは従来どおりのインク経済のまま変更していません。CPUはインク管理が苦手、という前提の**ハンデ**として、人間より速く・無条件に回復します。

- 地形によるインク回復速度: **自陣の色の上+35/秒・それ以外(未塗り/相手色とも)+8/秒**
- 撃っている最中やため中でも回復は止まらない(遅延なし)
- 武器ごとの消費インクはCPU用の既定値(シューター1発6・ローラー振り34・チャージャー基礎15+チャージ割合×35・バケツ1発19)で、移動塗り(ローラー・フデ)は完全に無料

## アバター

各プレイヤーが自分のキャラを作れます。武器選択画面の各プレイヤー側に「アバター」ボタン(今のアバターの顔つきをそのまま表示)があり、押すとその側にキャラクリ画面がオーバーレイで開きます(P2側は他の要素と同じく180度回転)。両者が同時に開いても問題ありません。すべてCanvasで描画しており、画像ファイルは使っていません。

- **選べるパーツ**: しゅぞく(イカ/タコ)・かみがた(ショート/ロング/ツインテール/ポニーテール/おだんご/ボウズの6種)・かみのいろ(8色)・め(まる/たれ/つり/ほし/ねむいの5種)・はだ(6色)・ぼうし/アクセ(なし+キャップ/リボン/ヘッドホン/めがね/はな/ヘルメットの6種)・ふくのいろ(8色)・なまえ(最大6文字)
- 「ランダム」ボタンで全パーツを一括ランダム化、「OK」で確定して選択画面に戻る
- 選択内容はP1/P2別に`localStorage`(`sploteen_avatar_v1_p1` / `_p2`)へ保存され、次回起動時も同じアバターで始まる(保存に失敗しても対戦は続行できる)
- キャラクリ画面には正面向き上半身の大きなプレビュー(約160px角)を表示
- アバターの見た目は完全に演出のみで、`simulate()` のゲームロジックには一切影響しません

### ゲーム中のアバター表示(第7ラウンドで拡大)

- 対戦中のキャラは、キャラクリのプレビューと同じ正面向き上半身の絵を高さ約54px(あたり判定`PLAYER_RADIUS`の約2.4倍の見た目。あたり判定自体は変えていません)で表示する。あらかじめオフスクリーンcanvasに描いておいた絵を毎フレーム`drawImage`で貼るだけなので描画コストは軽い

- HUDの武器アイコンの隣に、アバターの顔だけを描いた32px程度の丸いアイコンを表示(アバター変更時だけ再描画)
- カウントダウンの直前に1.2秒の「VS」画面を挟み、中央に「VS」、下にP1(なまえ・メイン武器名・アバター)、上にP2(180度回転、同様)を表示する
- ラウンド結果画面・優勝画面では、勝った側のアバターを大きく(約120px)・軽くはねるアニメーションつきで、負けた側は小さく横に表示する。ひきわけの場合は両方同じ大きさ。P2が勝った場合もその表示は180度回転してP2側から見える向きになる

## ボットと自動対戦API

`window.SPLOTEEN` に以下を公開しています(バランス調整・自動テスト用)。

```js
SPLOTEEN.WEAPONS        // メイン武器パラメータ。書き換えると次の対戦から反映される
SPLOTEEN.SUBS           // サブウェポンパラメータ
SPLOTEEN.SPECIALS       // スペシャルパラメータ(武器から独立)
SPLOTEEN.CONFIG         // { BOT_SKILL: 0〜1, ... } ボットの強さ・判断パラメータ
SPLOTEEN.simulate({ p1:'shooter', p2:'roller', sub1:'splashbomb', sub2:'quickbomb', sp1:'sensei', sp2:'manta', seed:1, duration:90, bot1:true, bot2:true })
  // 描画なしで1試合をヘッドレス実行。sub1/sub2・sp1/sp2省略時は各メインの既定サブ・既定スペシャルが使われる
  // { p1Pct, p2Pct, winner, splats, specials, kills, subs, statusHits, inkPainted } を返す
  // kills: [P1が倒した数, P2が倒した数] / subs: [P1のサブ使用回数, P2のサブ使用回数]
  // statusHits: [P1が状態異常を与えた回数, P2が状態異常を与えた回数]
SPLOTEEN.startMatch({ p1, p2, sub1, sub2, sp1, sp2, seed, bot1, bot2, duration })
  // 画面上でメニューをスキップして対戦を開始(sub1/sub2・sp1/sp2省略時は各メインの既定値)
SPLOTEEN.setInput(player, { move:{x,y}, aim:{x,y}, fire:bool, special:bool, sub:bool })
  // 外部から入力を強制注入(nullで解除)。sub:trueでサブウェポンを使用
SPLOTEEN.getState()      // 残り時間・各プレイヤーの状態(kills/sub/subsUsed/special/status含む)・塗り割合を取得
```

## URLパラメータ

URLパラメータでも直接対戦を開始できます。

```
index.html?p1=bucket&p2=brush&sub1=splashbomb&sub2=sprinkler&sp1=utsubo&sp2=manta&auto=1&bots=1&seed=123
```

- `p1` / `p2`: 使う武器(`shooter` / `roller` / `charger` / `bucket` / `brush`)
- `sub1` / `sub2`: 使うサブ(`splashbomb` / `quickbomb` / `sprinkler` / `shield`。省略時は各メインの既定サブ)
- `sp1` / `sp2`: 使うスペシャル(`sensei` / `utsubo` / `manta`。省略時は各メインの既定スペシャル)
- `auto=1`: タイトル・武器選択をスキップして直接カウントダウンへ
- `bots=1`: 両プレイヤーをボット操作にする。`bot2=1` ならP2だけボット(1人練習用)
- `seed`: 乱数シード
- `duration`: 1ラウンドの秒数(既定90。動作確認用に短縮できる)

ゲームロジックは1/60秒の固定タイムステップで決定論的に動作し、`Math.random` は使わず seed 付きの自前PRNG(mulberry32)のみを使用しています(同じseedなら常に同じ結果になることを確認済み)。

## 調整用の主なパラメータ

`index.html` 先頭にまとまっています。

- `CONFIG.BOT_SKILL`(既定0.6): ボットの強さ。反応の速さ・エイム精度に影響。CPUモードの「よわい/ふつう/つよい」ボタンがこれを0.35/0.6/0.85に切り替える
- `CONFIG.ADVANCE_BIAS`(既定0.6): ボットの塗り方向選択が相手の方向へ寄る強さ。会敵率(≒戦闘の起きやすさ)に直結する
- `CONFIG.SHOOTER_OUTRANGE_CHASE`(既定0.8): シューター・バケツのボットが、自分より射程の長い相手(チャージャー等)と対面したときに詰めるべきと判断する間合いを、相手の射程のこの割合まで引き上げる係数
- `BASE_SPEED` / `OWN_INK_MUL` / `ENEMY_INK_MUL`: 移動速度と地形補正
- `INK_REGEN_FAST` / `INK_REGEN_SLOW`: CPU用のインク回復速度(自陣上/それ以外)
- `INK_REGEN_OWN_HUMAN` / `INK_REGEN_UNPAINTED_HUMAN` / `INK_REGEN_ENEMY_HUMAN` / `INK_REGEN_DELAY`: 人間専用のインク回復速度と、消費後に回復が始まるまでの待ち時間
- `WEAPONS.*`: 各武器のダメージ・射程・塗り半径・移動速度・インク消費(CPU用/`human`内が人間用)など
- `SUBS.*`: 各サブの飛距離・ダメージ・インク消費など
- `SPECIALS.*` / `SPECIAL_GAUGE_MAX` / `SPECIAL_KILL_BONUS`: 各スペシャルのパラメータと共通ゲージ満タン値・倒した時の加算割合
- `SUB_COOLDOWN`(既定1.0秒): サブウェポン使用後の共通クールダウン
- `AVATAR_PARTS`: アバターの各パーツの選択肢一覧
- `WINS_NEEDED`(既定2): シリーズの先取本数
- `WALLS_CELL`: マップの壁配置(点対称)

## インク経済の実験計画法による検討(参考)

CPUも人間と同じインクルールにするかどうかを検討する過程で、実験計画法を使った調整を行いました。

CPU も人間と同じインクルールにする案は、3 段階 48 条件の直交表実験で検討したが、異種 10 組中 5 組までしか 35〜65% に収まらなかったため、CPU は従来のインク経済のままとした。最良条件: 回復 35/秒・待ち時間 0.25 秒・シューター 1 発 4・チャージャー 4+8・バケツ 14・転がし 0.15/セル・走り 0.06/セル・当たり判定半径 11・連射規律なし・CPU の回復モードあり・チャージャー塗り幅 2.0・チャージャーため 0.9 秒/速度 1.15・フデ速度 1.35

この結果を踏まえ、CPUは引き続き第5ラウンドまでと同じインク経済(自陣+35/秒・それ以外+8/秒、消費中も回復停止なし)で動かし、人間プレイヤーにだけ上記の専用インクルール(自陣35/未塗り8/相手0・回復遅延0.5秒・武器別の軽いインクコスト)を適用する、現在の方式を採用しています。
