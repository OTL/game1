# ドッキリ回避24時

テレビ局を歩いているだけなのに、あちこちにドッキリの仕掛けが待っている。
あやしいサインを見やぶって、ひっかからずに進むアクションゲームです。

**▶ https://otl.github.io/game1/dokkiri/**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。
絵も音もすべてプログラムで作っているので、画像・音声ファイルはありません。

## 遊び方

主人公は自動で右へ歩きます。仕掛けにあわせて 3 つの行動でよけます。

| 行動 | タッチ | キーボード | よける仕掛け |
| --- | --- | --- | --- |
| ▲ ジャンプ | 右下のボタン | `↑` / `Space` / `W` | バナナの皮・おとしあな・びっくり箱 |
| ▼ しゃがむ（おしている間） | 左下のボタン | `↓` / `S` | パイなげ・パンチグローブ |
| ■ ストップ（おしている間） | 左下のボタン | `←` / `A` | 金ダライ・こむぎこバケツ |

- ひっかかると仕掛け人が「ドッキリ大成功」のプラカードを持って出てくる。**3 回ひっかかるとロケ終了**
- よけるたびに +100 点。5 連続ごとにコンボ倍率が 0.5 ずつ上がる（最大 ×3）
- 金ダライ・こむぎこを目の前ギリギリでやりすごすと「ギリギリ」ボーナス
- 仕掛けを 10 こ通るごとにロケ地が変わり、少しずつ速くなる
  （テレビ局のろうか → しょうてんがい → おんせん旅館 → ホテルのろうか → …）
- はじめて出てきた仕掛けは、画面上に説明が出る
- `P` / `Esc` で一時停止、`M` で音のオン／オフ

## 仕掛けとサイン

| 仕掛け | サイン | よけ方 |
| --- | --- | --- |
| バナナの皮 | 床におちている | ジャンプ |
| おとしあな | 床にうすい四角い継ぎ目。近づくとパカッとひらく | ジャンプ |
| びっくり箱 | 床のプレゼント箱。近づくとバネのグローブが飛び出す | ジャンプ |
| パイなげ | 半分あいたドア。仕掛け人が「ニヤリ」と顔を出してからパイを投げる | しゃがむ |
| パンチグローブ | 柱の穴に赤いランプ。ふるえたら顔の高さにパンチ | しゃがむ（止まって引っこむのを待ってもいい） |
| 金ダライ | 天井からひもで吊られたタライ。ゆれたら落ちてくる | 下を通る前にストップ |
| こむぎこバケツ | 天井のバケツ。かたむいたら粉がふってくる | ストップして粉がやむまで待つ |

止まったまま待っていても、仕掛けは遠くから動き出すので、ずっと待つことはできません。

## かくしカメラ

背景の植木・絵・時計・たぬき・まねきねこ・ガチャガチャ・ちょうちん・かけじく・花びんに、
ときどき**かくしカメラ**がまぎれています。黒いレンズと赤いランプが目印。

- タップ（クリック）で見つけると +300 点
- **5 こ見つけるとライフが 1 つ戻る**（ライフが満タンなら +500 点）
