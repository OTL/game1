# ラビット・ホールデム

大人向けのテキサスホールデム（ノーリミット）です。カードの裏はうさぎ。

**▶ https://otl.github.io/game1/holdem/**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。
カードの絵も音もすべてプログラムで作っているので、画像・音声ファイルはありません。
スマホとタブレット向け（縦でも横でも遊べます）。

## 遊び方

- **CPU と対戦**：人間 1 人＋CPU（1〜7 人）
- **みんなで対戦**：人間を 2 人以上にすると、1 台の端末を回して遊べます。自分の番になると「○○の番です」と表示されるので、ほかの人に見えないようにしてからカードを見ます
- 人間と CPU はまぜられます（全部で 2〜8 人）

## ルール

| 項目 | 選べるもの |
| --- | --- |
| 形式 | **トーナメント**（チップがなくなったら退場、最後のひとりまで）／ **リングゲーム**（なくなったら補充して続け、やめたときの収支をくらべる） |
| 持ちチップ | 1,000 / 2,000 / 5,000 / 10,000 |
| ブラインド | 5/10 / 10/20 / 25/50 / 50/100 |
| ブラインド上昇（トーナメント） | なし / 5 / 10 / 15 / 20 ハンドごと |
| CPU の強さ | よわい / ふつう / つよい / まぜる |

- ノーリミット。最小レイズは直前のレイズ幅。足りないオールインではレイズの権利は戻りません
- サイドポット、引き分け（山分け）、ヘッズアップのブラインド位置に対応
- 全員オールインになったら手札を公開して最後まで配ります

## ヒント

設定で「表示する」にすると、手元に今の役と勝率（相手がランダムな手を持っているとして計算）が出ます。
画面右上の ♠ から、いつでも役の強さの一覧を見られます。

## CPU

モンテカルロ法で勝率を見積もり、ポットオッズ・相手の賭け方・ポジションを考えて動きます。

- **よわい**：ついコールしがち。ブラフはほとんどしない
- **ふつう**：勝率とポットオッズで素直に判断する
- **つよい**：相手の大きな賭けを警戒し、ブラフやスロープレイもまぜる。チップが少ないとオールインで勝負する

## テスト用

`index.html?auto=300&n=5&f=tour` のように開くと、全員を CPU にして高速で対戦し、チップの合計が合っているかを確認できます（`f=ring` でリングゲーム）。
