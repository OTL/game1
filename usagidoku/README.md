# うさどく

Meowdoku 風のロジックパズルです。ねこのかわりにうさぎをならべます。

**▶ https://otl.github.io/game1/usagidoku/**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。
絵も音もすべてプログラムで作っているので、画像・音声ファイルはありません。

## ルール

1. 色のくぎりごとに、うさぎを 1 わずつおく
2. たての列にも、よこの列にも 1 わずつ
3. うさぎどうしはとなりあわない（ななめもダメ）
4. ステージ 101 からは **いわ** のマスがでてくる。いわにはうさぎをおけない（さいしょから ✕ がついているのとおなじ）
5. ステージ 151 からは上級の **だい3しょう**。いわはないけれど、むずかしい推理がいる

答えはどのステージも 1 とおりだけで、あてずっぽうなしで推理だけで解けます。

## 操作

| 操作 | タッチ／マウス |
| --- | --- |
| ✕ じるしをつける・消す | タップ |
| ✕ をつづけて書く・消す | なぞる |
| うさぎをおく | ダブルタップ（うさぎモードならタップ） |

- うさぎのいないマスにうさぎをおくと、ニンジンが 1 本へる。3 本なくなるとやりなおし
- うさぎをおくと、おけなくなったマスに自動で ✕ がつく（せっていで切りかえ）
- **もどす** は ✕ をひとつ前にもどす。**✕ を消す** は ✕ をぜんぶ消す
- **ヒント** は ✕ をつけられるマスをひとつ光らせて、そのわけ（点線のマスが手がかり）をおしえる。うさぎのいるマスに ✕ をつけていたら、場所はいわずにその数だけおしえてくれる
- まちがい・ヒントなしでクリアすると ★3、あわせて 1 回までなら ★2
- **きせかえ**: ★ の合計で、うさぎのおしゃれがふえる（せってい ⚙ からえらぶ）

| ★ | きせかえ |
| --- | --- |
| 30 | リボン |
| 90 | おはな |
| 160 | ちょうネクタイ |
| 250 | めがね |
| 360 | おうかん |

## ステージ

| ステージ | 大きさ |
| --- | --- |
| 1〜10 | 5×5 |
| 11〜25 | 6×6 |
| 26〜45 | 7×7 |
| 46〜65 | 8×8 |
| 66〜85 | 9×9 |
| 86〜100 | 10×10 |
| 101〜110 | 8×8（いわあり） |
| 111〜125 | 9×9（いわあり） |
| 126〜140 | 10×10（いわあり） |
| 141〜150 | 11×11（いわあり） |
| 151〜156 | 9×9（上級） |
| 157〜164 | 10×10（上級） |
| 165〜172 | 11×11（上級） |
| 173〜180 | 12×12（上級） |

だい2しょう（101〜）は、いわで答えを 1 とおりにしぼっているので、いわのまわりが推理の手がかりになります。どのいわも、ないと答えが 1 とおりにならないものだけをおいています。

だい3しょう（151〜）は上級ステージです。どのステージも、3 つ以上のくぎり（または列）をくみあわせて「この 3 つのくぎりは この 3 列におさまるから、ほかのくぎりはこの 3 列におけない」と考える推理が 1 回以上、2 つ以上をくみあわせる推理があわせて 2 回以上いるものだけをえらんでいます（だい1・2しょうでは 150 ステージ中 10 ほどしかない むずかしさです）。

おなじ大きさの中では、あとのステージほど推理がむずかしくなります。
クリアした星とベストタイムはブラウザ（localStorage）に保存されます。
とちゅうの盤面は **セーブ 💾** ボタンで保存でき、つぎにそのステージ（またはタイトルの「つづきから」）をえらぶと続きからあそべます。セーブできるのは 1 ステージぶんだけで、クリアするかニンジンがなくなると消えます。

ステージは `tools/generate.js`（`node tools/generate.js out.json`、いわのステージは `node tools/generate.js --rocks out.json`、上級ステージは `node tools/generate.js --hard out.json`）で作ったものを `index.html` の `PUZZLES` に入れています。
いわのステージでは、いわのマスを小文字で、答えの列を 36 進数（11×11 の 10 列目は `a`）で書いています。上級ステージも答えの列は 36 進数で、12×12 のくぎりは A〜L です。
