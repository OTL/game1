# ツインマレット・ホッケー

ゲームセンターのエアホッケーを、ブラウザで 2 人対戦できるようにしたゲームです。
ふつうのエアホッケーと違うところは 2 つ。

- **1 人が両手で 2 つのマレットを動かす**（指 2 本でなぞる／キーボードなら左手・右手で別々のキー）
- **試合中にパックがどんどん増える**（最後は最大 7 個の乱戦になる）

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

**▶ https://otl.github.io/game1/hockey/**

## 遊び方

タブレットやスマホを 2 人のあいだに置いて、向かい合わせで座ります。
下側が **1P（水色）**、上側が **2P（オレンジ）**。相手のゴールにパックを入れると得点です。

### 操作

| 環境 | 操作 |
| --- | --- |
| タブレット / スマホ | 自分側の半面を **指 2 本**でなぞる。指 1 本ごとに、近いマレットがついてくる |
| マウス | ドラッグでマレット 1 つを動かす（CPU 対戦のおためし向け） |
| キーボード | 1P 左手 `W A S D` ／ 1P 右手 `↑ ← ↓ →`<br>2P 左手 `T F G H` ／ 2P 右手 `I J K L`（2P は向かい合わせなので上下左右が反転します） |

- `P` または `Esc` で一時停止（画面右下の「‖ 休止」ボタンでも可）
- `M` で音のオン／オフ
- マレットは自分のコートとクリースの外にしか置けません。点線のリングは「いま指で持っていないマレット」です

### ルール

- 相手のゴールに入れると **1 点**
- 自分のゴールの真ん前には **クリース**（点線の帯）があり、マレットは入れません。ゴールラインに 2 本を並べて
  完全にふさぐことはできないので、斜めから来るシュートは横を抜けて入ります
- 試合時間は 60 / 90 / 120 秒から選択。時間切れで同点なら **サドンデス**（先に 1 点とった方の勝ち）
- 失点すると、そのパックはすぐ中央から復活します（パックの数は減りません）

### パックが増える

試合時間を均等に割ったタイミングで、パックが 1 個ずつ中央から追加されます
（最大数を 5 個にすると、90 秒なら 18 秒ごとに 1 個ずつ）。
追加されるパックは 4 種類のどれかです。

| パック | 見た目 | 特徴 |
| --- | --- | --- |
| ノーマル | 白 | ふつうのパック |
| スピード | ピンク・`S` | 小さくて軽い。よく跳ねてとても速い |
| ヘビー | 灰色・`H` | 大きくて重い。押し返しにくいが、当てれば止まらない |
| ゴールデン | 金色・`2` | **決めると 2 点**。ただし取られても 2 点 |

守りに 1 本、攻めに 1 本。両手の役割分担ができると一気に有利になります。

## 設定

タイトル画面で選べます。

- **モード**：2 人対戦 / CPU 対戦
- **CPU のつよさ**：よわい / ふつう / つよい / 鬼（CPU も両手で 2 本のマレットを操作します）
- **試合時間**：60 / 90 / 120 秒
- **パックの最大数**：3 / 5 / 7 個

## 技術メモ

- `index.html` 1 ファイル完結。Canvas 2D + WebAudio のみで、画像・音声ファイルなし
- フィールドは 620 × 1040 の論理座標で持ち、画面サイズにあわせて拡大縮小（縦長固定）
- パックは 1 フレームを 4 分割して積分し、すり抜けを防止。マレットは無限質量として相対速度を反発させ、
  動かした勢いがそのままパックに乗る
- ゴールポストは静的な円として当たり判定を持つので、ポストに当たって跳ね返る
- マレットの位置とねらいは「自陣 → クリースの外 → 壁の内側」の順に丸めるので、マレット同士を押し合っても
  クリースには入れない
- ポインタイベントの `pointerId` ごとにマレットを 1 本ずつ割り当てることでマルチタッチに対応
