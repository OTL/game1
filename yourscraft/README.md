# YoursCraft

ブラウザで遊べる、マインクラフト風のブロック建築ゲームです。
**クリエイティブモード専用**・**タブレットのタッチ操作前提**・**自動セーブ**。

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます（WebGL2 対応ブラウザが必要）。

**▶ https://otl.github.io/game1/yourscraft/**

## これは何

- 無限に広がるブロックの世界を、こわす・つくる・飛ぶだけのゲーム
- 体力も空腹もモンスターもいない。落ちても死なない。ただ建てるだけ
- 夜がきたら**ベッド**で寝れば朝。夜そのものがいらないなら設定で**夜にしない**
- 家には**ドア**。たて 2 マスで、タップ（右クリック）であけしめできる
- 地形は **seed（種）から生成**。同じ seed なら何度でも同じ世界が生まれる
- 遊んだ内容は**数十秒ごとに自動で保存**される（ブラウザを閉じても続きから遊べる）

## 遊び方

### タブレット / スマホ

| やりたいこと | 操作 |
| --- | --- |
| 見まわす | 画面を指でなぞる |
| 歩く | 左下のスティック（いっぱいに倒すとダッシュ） |
| ブロックを置く | 置きたい場所のブロックを **タップ**（触ったブロックの手前に置かれる）<br>または右の **▣ おく** ボタン（画面中央の十字の位置） |
| ブロックを壊す | 壊したいブロックを **長押し**（押したままなぞると続けて壊せる）<br>または右の **⛏ こわす** ボタン |
| ジャンプ | 右下の ⤒（2 回つづけて押すと飛行モードに切りかえ） |
| 飛ぶ | ✈ で切りかえ → ▲ で上昇 / ▼ で下降 |
| ベッドを置く | ベッドは **2 マス**つかう。頭は自分が向いているほうへのびるので、その先を 1 マスあけておく |
| ベッドでねる | 置いた**ベッドをタップ**（頭・足もとどちらでも。夜のあいだだけ） |
| ドアを置く | ドアは **たて 2 マス**つかう。地面の上に、上を 1 マスあけて置く |
| ドアをあけしめ | 置いた**ドアをタップ**（上でも下でも） |
| ブロックを選ぶ | 下のホットバーをタップ（長押しでインベントリ） |
| インベントリ | 右上の ⊞ |
| メニュー | 右上の ‖ |

「タップで壊す／長押しで置く」に入れかえる設定もあります。

## 中身

### 世界

- 1 チャンク 16 × 96 × 16。プレイヤーのまわりを順に読み込み、離れたら捨てる
- バイオーム 7 種（平原・森・砂漠・雪原・山岳・砂浜・海）
- 洞窟（細いトンネル + 深い大空洞）、地下の溶岩だまり
- 鉱石は**鉱脈**として塊で生成（石炭・鉄・金・レッドストーン・ダイヤ・エメラルド）
- 木はオーク・シラカバ・トウヒの 3 種。花・草・サボテン・カボチャも生える
- ブロックは 69 種類（羊毛 16 色・ベッド・ドアを含む。ベッドは向きと頭／足もとで内部的に 8 種、
  ドアは向き × あけしめ × 上下で 16 種）

### 見た目

マイクラの画面に寄せるために入れてあるもの：

- **スムースライティング + AO**：空の光とブロックの光を別々に頂点へ持たせているので、
  昼夜が変わってもメッシュを作り直さずに明るさだけが変わる
- **松明・グロウストーン・溶岩の光**が周囲に広がる（幅優先探索で 15 段階）
- **昼夜サイクル**（20 分で 1 日）、朝焼け・夕焼け、星、月の満ち欠け
- **ベッド**はマイクラと同じで **2 マス**（頭＋足もと）・高さ 9/16。向き 4 方向ぶんの
  ブロックを用意してあり、つなぎ目の面は描かない。夜に使うと暗転して**朝まで飛ぶ**
- **ドア**はマイクラと同じで **たて 2 マス**・厚さ 3/16 の板。あけると、ちょうつがい側へ
  90 度ひらく（向き 4 方向 × あけしめ × 上下の 16 種）。あいているあいだは横をすり抜けられる
- **雲**（板 1 枚に手続き生成テクスチャ。角がきっぱりしたマイクラ風）
- **水**はゆらぎ、水面は少し低い。水中は青くかすむ
- **葉・ガラス・草花**はアルファ抜き、**手に持ったブロック**は画面の隅で揺れる
- ブロックのテクスチャは全部コードで描いた 16×16 のドット絵（画像ファイルを 1 枚も使っていない）

### セーブ

地形は seed から再現できるので、保存するのは

- メタ情報（seed / プレイヤーの位置 / 時刻 / ホットバー / 設定）
- **プレイヤーが置いた・壊したブロックだけ**（チャンクごとの差分）

だけです。IndexedDB に書き、使えない環境では localStorage に落とします。
8 秒ごと・画面を離れたとき・メニューに戻ったときに自動保存します。

## 技術的なこと

- **WebGL2 直書き**（three.js などは使っていません）。ブロックの面は 2D 配列テクスチャの
  レイヤーとして参照するので、ミップマップを使ってもタイルの境目がにじみません
- 1 頂点 20 バイト（位置 12 + タイル 2 + UV 2 + 光/AO/波 4）にパックして 1 チャンク 1 バッファ
- 不透明 / アルファ抜き / 半透明の 3 パスに分け、水のチャンクは奥から手前へ並べ替え
- チャンクの「地形 → 光 → メッシュ」を 1 フレームあたりの時間予算内で少しずつ進めるので、
  歩いていても止まりません（実測で 1 チャンクあたり 地形 4.4ms / 光 3.2ms / メッシュ 3.6ms）
- 視錐台カリング、チャンクの高さによる早期除外

## 動作環境

WebGL2 が必要です。iPad は iOS 15 以降の Safari、Android は Chrome、
パソコンは Chrome / Edge / Firefox / Safari で動きます。

重いときは設定で **描画距離**（3〜12 チャンク）と **解像度**（60〜100%）を下げてください。
タブレットでは初期値を「5 チャンク・75%」にしてあります。

## ファイル

```
yourscraft/
├── index.html      … 画面（HUD・メニュー・インベントリ）
├── css/style.css   … 見た目
└── js/
    ├── noise.js    … 乱数とパーリンノイズ
    ├── blocks.js   … ブロック定義とテクスチャ生成
    ├── worldgen.js … 地形・バイオーム・洞窟・鉱脈・木
    ├── world.js    … チャンク管理・光の伝播・メッシュ生成
    ├── render.js   … WebGL2 描画（空・雲・水・パーティクル）
    ├── player.js   … 移動と当たり判定
    ├── audio.js    … 効果音（WebAudio で合成）
    ├── save.js     … 自動セーブ（IndexedDB / localStorage）
    ├── ui.js       … アイコン・ロゴ生成
    └── main.js     … ゲームループと操作
```
