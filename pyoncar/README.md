# ぴょんカー・エボリューション

うさぎの乗った車をパチンコで打ち出し、でこぼこのコースを奥へ走らせる 3D ゲームです。
集めたお金で車を強化すると、段ボールカーがジェットカーまで進化します。

**▶ https://otl.github.io/game1/pyoncar/**

スマホ縦持ち向け（PC でも遊べます）。進みぐあいはブラウザに自動で保存されます。
3D の描画には [three.js](https://threejs.org/)（r170, MIT ライセンス）を使い、`three.module.min.js` をこのディレクトリに同梱しています。外部の CDN には頼りません。

## 遊び方

1. **発射**：画面を下にひっぱって離すと、パチンコで車が飛び出します。ひっぱった長さがパワー、左右にずらすとねらいが変わります
2. **走る**：燃料はありません。発射の勢いだけで進みます。左右にドラッグするとハンドルを切れます（PC は ← → キー、発射はスペースキー長押しでも可）
3. **ジャンプ**：画面をタップ（または上にスワイプ、右下のボタン、PC はスペース／↑）でぴょんとジャンプ。岩やぬかるみを飛び越せます。速いときは宙返りし、長く飛ぶと「ナイスジャンプ」のボーナス。着地すると少し待ってから次のジャンプができます
4. **ゴール**：ゴールのゲートまで届けばクリアで、次のステージが開きます。届かなくても、走った距離とひろったコインがお金になります
5. **強化**：ガレージでお金を使ってパーツを強化し、もっと遠くを目指します

## コースのしかけ

| しかけ | 効果 |
| --- | --- |
| でこぼこ道 | 通るあいだ減速する（ばねの強化で軽くなる） |
| ぬかるみ（こげ茶） | 大きく減速する（タイヤで軽くなる） |
| 岩 | ぶつかるとスピードが約 2 割落ちる |
| 道の外（野原） | 柵はなく、道の外も走れる。少し減速し、外へ行くほど山の斜面になって押し戻される |
| ジャンプ台（しましま） | 飛び越せる。着地でスピードが少し落ちる |
| 加速パネル（黄色） | 通っているあいだ加速する |
| 坂・かたむき | 下りで加速、上りで減速。横にかたむいた所では低いほうへ流される |

## 演出

スピードが上がると画面にスピード線が走り、画角が広がります。100・150・200km/h を超えると表示が出ます。
ブーストの炎、岩にぶつかったときの火花と画面のゆれ、着地の土ぼこり、ゴールの紙吹雪などがあります。

## 強化と進化

| パーツ | 効果 |
| --- | --- |
| ひっぱり力 | 発射スピードが上がる |
| タイヤ | よく転がる・ぬかるみに強くなる |
| ばね | でこぼこと着地で減速しにくくなる |
| ボディ | 空気抵抗が減る |
| ハンドル | 左右にすばやく動ける |
| コイン磁石 | コインを遠くから吸い寄せ、コインの価値が上がる |
| ジャンプ力 | ジャンプが高くなり、次のジャンプまでの待ち時間が短くなる |

各パーツは Lv 25 まで。合計レベルが 6・18・36・60 になると車が進化します
（段ボールカー → 木の荷車 → バギー → スポーツカー → ジェットカー）。
進化するたびに発射スピード・ころがり・コインの価値にボーナスがつきます。

## ステージ

草原の道・なだらかな丘・でこぼこ道・砂漠・砂丘・森の小道・深い森・雪山・氷の谷・火山・溶岩の川・月面・星の海の全 13 ステージ。
そのあとはエクストラステージが続きます。雪山はすべりやすく、月面は重力が小さいので大きく跳ねます。

コースは毎回同じ形です。ゴールは 300m（ステージ1）から 3100m（ステージ13）まで。各ステージのゴール距離は、目安の強化レベルで自動運転したときに届く距離をもとに決めています。

## 調整用の URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?reset` | セーブを消して最初から |
| `?money=N` | 所持金を N にする |
| `?lv=N` | 全パーツを Lv N にする |
| `?stage=N` | ステージ N まで開放して選ぶ |
| `?auto` | 走行中のハンドルを自動運転にする |

ブラウザのコンソールで `__sim({runs:200, stages:13})` を実行すると、自動プレイで何回の挑戦で各ステージをクリアできるかを調べられます。
