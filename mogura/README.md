# モグラたたきアーケード

ゲームセンターにあるモグラ叩きを、ブラウザで遊べるようにしたゲームです。
ふつうのモグラたたきと違うのは操作で、**ハンマーを自分で運ぶ**ところ。

- **ハンマーをモグラのところまで移動させて、ダブルタップで叩く**
- **たまに出てくるうさぎを叩くと −2 点**
- 制限時間は **30 秒**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。

**▶ https://otl.github.io/game1/mogura/**

## 遊び方

画面をなぞるとハンマーがついてきます。ハンマーはゆっくり動くので、
モグラが出てから運んでいては間に合いません。次に出そうな穴のそばで待つのがコツです。

ねらった場所で **ダブルタップ（2 回クリック）** すると振り下ろします。
振っているあいだ（約 0.2 秒）はハンマーを動かせないので、から振りすると次の 1 匹に間に合いません。

### 操作

| 環境 | 操作 |
| --- | --- |
| タッチ | 指でなぞって移動 → その場で **ダブルタップ** |
| マウス | 動かして移動 → **ダブルクリック** |
| キーボード | `W A S D` / `↑ ← ↓ →` で移動、`Space` を **2 回連打** で叩く |

- `P` または `Esc` で一時停止
- `M` で音のオン／オフ

### とくてん

| 出てくるもの | 見た目 | 点数 |
| --- | --- | --- |
| モグラ | 茶色 | **+1** |
| キラモグラ | 金色・キラキラ | **+3**（出ている時間が短い） |
| うさぎ | 白・長い耳・`−2` マーク | **−2**（コンボもリセット） |

- モグラを連続で叩くとコンボがのび、**5 連続ごとに +1 のボーナス**がつきます
- から振りとうさぎでコンボはリセット。うさぎだけはしっかり見てから振りましょう
- スコアはマイナスにもなります

## 設定

タイトル画面で選べます。

- **むずかしさ**：やさしい / ふつう / おに（出現間隔・同時に出る数・うさぎの割合が変わります）
- **ハンマーの動き**：おもい / ふつう / かるい（ハンマーの移動速度）

むずかしさごとにハイスコアを `localStorage` に保存します。

## 技術メモ

- `index.html` 1 ファイル完結。Canvas 2D + WebAudio のみで、画像・音声ファイルなし
- フィールドは 640 × 900 の論理座標で持ち、画面サイズにあわせて拡大縮小（レターボックス）
- 穴は 3 × 3。手前の行ほど大きく描いて奥行きを出している
- モグラは穴の上側とふちの内側の和をクリップ領域にして描くので、下半分が穴に隠れて見える
- ダブルタップは「340ms 以内・論理座標で 110px 以内の 2 回目のポインタダウン」で判定
- 当たり判定はスイング開始から 115ms 後の 1 回だけ。ハンマー位置と、出ている（rise > 0.38）モグラの
  楕円距離がいちばん近いものを 1 匹だけ叩く
- 試合が進むほど出現間隔と滞在時間が短くなる（経過時間で線形に補間）
