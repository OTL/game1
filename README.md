# ボムよけゲーム

上から降ってくる爆弾をよける HTML5 Canvas ゲームです。
依存パッケージなし・単一ファイル。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

- 左右に動き、ジャンプして、落ちてくる爆弾をよける
- 残機は 3（ハートで最大 5 まで回復）。0 になるとゲームオーバー
- 生存時間に応じてスコアが加算される
- 通常の爆弾を地面まで落とし切ると +5 点

### 赤い爆弾は爆発する

**赤く脈打つ爆弾**は、着地すると周囲に爆風を広げます。爆風は地面から一定の高さまでしか届かないので、
**ジャンプでよけられます**。直撃した場合もその場で爆発します。

### アイテム

| アイテム | 効果 |
| --- | --- |
| ★ スター | +100 点 |
| ◆ ジェム | +300 点 |
| ♥ ハート | ライフ +1（最大 5、上限時は +200 点） |
| 🛡 シールド | 6 秒間無敵。爆弾・爆風をガードする |
| ◷ スロー | 5 秒間、爆弾の落下が 0.42 倍になる |

## 操作

| 操作 | キー / 入力 |
| --- | --- |
| 移動 | ← → キー、A / D キー、ドラッグ、画面下の ◀ ▶ ボタン |
| ジャンプ | スペース / ↑ / W キー、ジャンプボタン（空中でもう一度押すと 2 段ジャンプ） |
| 一時停止 | P キー |
| スタート / リスタート | スペースキー、または画面のボタン |

## 難易度

`DIFFICULTY_SCALE` 定数（既定値 **3**）で全体の強さが決まります。この値を変えるだけで調整できます。

- 難易度の進行が SCALE 倍速くなる（3 なら 30 秒で最大強度、1 なら 90 秒）
- 出現頻度・落下速度の上限も連動して上がる
- 赤い爆弾の出現率は 16% → 40% まで上昇

`1` にすると従来どおりの難易度に戻ります。
