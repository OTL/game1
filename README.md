# CHAIN BLAST

ブロックブラスト風の 8×8 ブロックパズル。本家の気持ちよさはそのままに、
**連鎖する特殊ブロック**・**コンボ倍率**・**パワーアップ**を足して駆け引きを増やしたゲームです。

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます（PC / スマホ両対応）。

```
# ローカルサーバで開く場合
npx http-server -p 8080 .
# → http://localhost:8080
```

## 遊び方

3 つのピースを盤面にドラッグして配置し、縦か横の 1 列を埋めると消えます。
ピースは回転できないので、置き場所の読みがすべて。3 つ使い切ると次の 3 つが配られます。
置ける場所が無くなったら終了です。

- **ドラッグ**して配置（スマホでは指の少し上にピースが浮きます）
- **タップで選択 → マス目をタップ**でも配置できます
- キーボード: `1` `2` `3` パワーアップ / `Esc` 選択解除 / `R` リスタート

## 本家との違い（面白さのために足した要素）

| 要素 | 内容 |
| --- | --- |
| 💣 ボム | ライン消しに巻き込むと周囲 3×3 を爆破。巻き込んだ先の特殊ブロックも起爆して **連鎖** する |
| ⭐ スター | 消えると縦横 1 列をまるごと消す。こちらも連鎖する |
| 🪨 ストーン | レベルアップで盤面に出現する障害物。2 回ライン消しに巻き込まないと壊れない |
| COMBO | ライン消しのたびに倍率アップ（最大 ×5）。**消せなかったターンは 1 段下がるだけ**なので、本家より粘って伸ばせる |
| PERFECT COLOR | 1 列を同じ色だけで揃えると大量ボーナス |
| ALL CLEAR | 盤面を空にすると +300 |
| CHARGE / パワーアップ | 消したマス数でゲージが溜まり、🔨ハンマー・💣ボム・🎲シャッフルを獲得 |
| レスキュー | ゲームオーバー時に 1 回だけ下 3 行を消して復活できる |

詰んでもパワーアップを持っていれば即ゲームオーバーにはならず、
盤面を崩して立て直すチャンスがあります。

## 構成

```
index.html      画面構造
css/style.css   スタイル・アニメーション
js/pieces.js    ピース形状の定義と生成（回転形は自動展開）
js/audio.js     WebAudio による効果音（音声ファイル不要）
js/game.js      盤面・スコア・連鎖・ドラッグ操作などゲーム本体
```

スコアと最高記録、サウンド設定は `localStorage` に保存されます。
