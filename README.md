# game1

ブラウザで遊べる HTML5 ゲーム置き場。GitHub Pages で公開しています。

**▶ https://otl.github.io/game1/**

| ゲーム | 内容 |
| --- | --- |
| [みんなでたまごっち](monster/) | アクセスした人みんなで 1 匹のモンスターを育てる。ドット絵は自動生成、進化ぶんき・タイプ相性バトルつき |
| [ボムよけゲーム](bomb-dodge/) | 上から降ってくる爆弾を左右移動とジャンプでよける。赤い爆弾は着地すると爆発する |
| [CHAIN BLAST](chain-blast/) | ブロックブラスト風の 8×8 ブロックパズル。連鎖・コンボ倍率・パワーアップ付き |
| [おえかきスタジオ](paint/) | アイビスペイント風のお絵かき。筆圧・手ブレ補正・レイヤー・お題チャレンジ付き |
| [シルエットクイズ](silhouette/) | 黒い影が何かを当てる。回転・反転・拡大クロップでかなり難しい。3 段階の難易度・約 140 問 |
| [コズミック・イーター](cosmic/) | 岩のかけらから天体を喰らって成長し、ブラックホールを目指す宇宙育成ゲーム。ヴァンサバ風の強化選択つき・約60分 |

どれも依存ライブラリなしで、各ディレクトリの `index.html` をブラウザで開くだけで遊べます。
詳しい遊び方は各ディレクトリの README を参照してください。

## 構成

```
.
├── index.html         … トップページ（ゲーム一覧）
├── assets/            … トップページ用のスクリーンショット
├── monster/           … みんなでたまごっち
├── bomb-dodge/        … ボムよけゲーム
├── chain-blast/       … CHAIN BLAST
├── paint/             … おえかきスタジオ
├── silhouette/        … シルエットクイズ
└── cosmic/            … コズミック・イーター
```

`.nojekyll` を置いて Jekyll の処理を無効化し、静的ファイルをそのまま配信しています。

## ローカルで開く

```
npx http-server -p 8080 .
# → http://localhost:8080/
```
