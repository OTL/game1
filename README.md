# ボムよけゲーム

上から降ってくる爆弾をよける HTML5 Canvas ゲームです。
依存パッケージなし・単一ファイル。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

- 左右に動いて、落ちてくる爆弾をよける
- 残機は 3。爆弾に当たると 1 つ減り、0 になるとゲームオーバー
- 生存時間に応じてスコアが加算される
- 爆弾を地面まで落とし切ると +5 点
- ★アイテムを取ると +100 点
- ハイスコアはブラウザの localStorage に保存される

## 操作

| 操作 | キー / 入力 |
| --- | --- |
| 移動 | ← → キー、A / D キー、タッチ・マウスのドラッグ |
| 一時停止 | P キー |
| スタート / リスタート | スペースキー、または画面のボタン |

時間が経つほど爆弾の落下速度と出現頻度が上がり、後半は同時出現も発生します（約 90 秒で最大難度）。
