# みんなでたまごっち

**アクセスした人みんなで、1 匹のモンスターを育てる**育成ゲーム。
たまごっち的なおせわ＋ポケモン風のドット絵＋数値パラメータ＋タイプ相性つきバトル。
依存ライブラリなし。`monster/index.html` をブラウザで開くだけで動きます（PC / スマホ両対応）。

```
# ローカルサーバで開く場合（リポジトリのルートで）
npx http-server -p 8080 .
# → http://localhost:8080/monster/
```

このゲームは `monster/` 配下で完結していて、他のゲームとはファイルを共有しません。

## 「みんなで育てる」の仕組み

サーバを持たない静的サイトなので、**時計を共有する**ことで「同じコを育てている」状態を作っています。

| しくみ | 内容 |
| --- | --- |
| **世代（シーズン）** | `2026-01-01 00:00 UTC` からの経過時間を 7 日で割った番号。これがタマゴのシードになります |
| **決定的な生成** | 種族・タイプ・体型・色・名前・進化さきは、そのシードだけから決まります。**同じ 7 日間にアクセスした人は、世界じゅうどこでも まったく同じモンスターに会えます** |
| **時間で育つ** | 経験値は 2 分に 1 ずつ自然に増えます。誰も来ていない間もそのコは育っていて、久しぶりに来た人も「みんなが育てた結果」に合流します |
| **きょうのぬし** | 日付から決まる強敵。その日は世界共通の相手で、1 日 1 回だけ挑めます |
| **おせわの記録** | おせわ回数・とっくん・戦績・ログは、共有ストレージがあればそこに、なければブラウザに貯まります（下記） |

### おせわの記録を、ほんとうに全員で共有する

既定では、記録は**あなたのブラウザ**（と、その別タブ。`BroadcastChannel` で即同期）に保存されます。
JSON を `GET` / `PUT` できる置き場を用意して URL を渡すと、そこを共有ノートにして全員の記録がひとつにまとまります。

- 画面右上の **「？ あそびかた」→ URL を入れて「つなぐ」**
- もしくは `?sync=https://...` を URL に付ける
- もしくは `index.html` で `window.MONSTER_SYNC_URL` を定義しておく

エンドポイントに求めるのは次の 2 つだけです。CORS を許可してください。

```
GET  <url>  → 200 で state の JSON を返す
PUT  <url>  ← state の JSON を丸ごと受け取って保存する
```

複数の人が同時に書いても壊れないよう、取りこみ時に**マージ**しています
（累計値は大きいほう、おせわメーターは新しいほう、ログは時刻順にマージして最新 40 件）。
20 秒ごとに取得、書きこみは 0.9 秒デバウンスです。

## そだてかた

| ボタン | 効果 |
| --- | --- |
| 🍚 ごはん | まんぷく +28 / EXP +8 |
| 🍰 おやつ | まんぷく +12・きげん +12・せいけつ −5 / EXP +5 |
| 🎾 あそぶ | きげん +24・げんき −12・まんぷく −6 / EXP +11 |
| 🛁 おふろ | せいけつ +42 / EXP +6 |
| 💤 ねかす | げんき +46・まんぷく −8 / EXP +6 |
| ✋ なでる | きげん +8 / EXP +3（タマゴのうちからできる） |

4 つのメーターは時間で減ります（まんぷくは 8 時間、きげん 10 時間、げんき 13 時間、せいけつ 15 時間で 0 になるペース）。
ただし**自然減だけでは 20 より下には落ちません** — 久しぶりに来た人がいきなり詰まないようにしてあります。

メーターの平均が**コンディション**（72〜100%）になり、こうげき・ぼうぎょ・すばやさに直接かかります。
放っておくと数字がそのまま弱くなる、というのがこのゲームの「たまごっち」部分です。

### とっくんと、進化の分岐

げんきを 18 使って、たいりょく／こうげき／ぼうぎょ／すばやさ のどれかを **+4**（各 120 まで）。
ポケモンの努力値のように、そのままステータス計算に乗ります。

```
さいだい HP = ⌊(種族値HP × 2 + とっくんHP) × Lv ÷ 100⌋ + Lv + 10
こうげき   = ⌊(⌊(種族値A × 2 + とっくんA) × Lv ÷ 100⌋ + 5) × コンディション⌋   （ぼうぎょ・すばやさも同じ）
```

**いちばん伸ばした値で、Lv.26 の最終進化の姿と名前が変わります**（ちからがた／まもりがた／はやさがた／たいりょくがた）。
みんなで方針がバラバラだと、どこに進化するかで綱引きになります。

### 成長

| ステージ | 条件 | 見ため |
| --- | --- | --- |
| タマゴ | EXP < 30 | 模様つきのタマゴ。ゆらゆら動く |
| ベビー | Lv.1〜9 | 頭が大きい小さい姿 |
| 中間 | Lv.10〜25 | ひとまわり大きく |
| 最終 | Lv.26〜 | とっくんの分岐で 4 通り。ツノ・プレート・ヒレなどが増える |

7 日たつと世代が交代し、次のタマゴがやってきます。

## バトル

ターン制。行動順は すばやさ で決まります（遅くても 12% で先手）。

```
ダメージ = ⌊(⌊(2 × Lv ÷ 5 + 2) × いりょく × こうげき ÷ ぼうぎょ ÷ 50⌋ + 2)
           × タイプ相性 × タイプ一致(1.5) × 乱数(0.85〜1.0) × きゅうしょ(1.6)⌋
```

タイプは ほのお・みず・くさ・でんき・いわ・ひこう・あく・フェアリー の 8 種。
それぞれ 2 つの得意な相手（×2）と 2 つの苦手（×0.5）を持ち、相手が 2 タイプなら掛け算されます（最大 ×4）。

- **⚔️ たびに でる** — 野生のモンスターと戦う。げんきを 12 使います
- **👑 きょうの ぬしに いどむ** — その日限定の強敵（Lv +5 / ステータス ×1.18）。1 日 1 回、経験値は大きめ
- **📣 みんなで おうえん** — ターンを使ってこうげき +15%（最大 1.6 倍）と少し回復
- **🏃 にげる** — すばやさ差で成功率が変わります

負けても経験値は少しもらえますが、きげんとげんきが下がります。

## 画像について

画像ファイルは 1 枚も使っていません。すべて `js/sprite.js` が
64×64 のグリッドに楕円やスパイクを描き、**フチどり・上のハイライト・下の影**を自動でつけて
その場で生成しています。つばさやしっぽは別レイヤーに描いてから先にフチをつけ、
胴体に溶けこまないようにしています。

```
    ├── state.js    … 世界の時計・パラメータ・保存・マージ

    ├── battle.js   … バトルエンジン
    └── game.js     … 画面と演出
```
