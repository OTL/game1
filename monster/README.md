# たまごっち

**七日間、いきものを ひとり育てる**育成ゲーム。
たまごっち的なおせわ ＋ ポケモン風のドット絵 ＋ 数値パラメータ ＋ タイプ相性つきバトル。
依存ライブラリなし。`monster/index.html` をブラウザで開くだけで動きます（PC / スマホ両対応）。

```
# ローカルサーバで開く場合（リポジトリのルートで）
npx http-server -p 8080 .
# → http://localhost:8080/monster/
```

このゲームは `monster/` 配下で完結していて、他のゲームとはファイルを共有しません。

## 設計の背骨

| | |
| --- | --- |
| **完全ローカル** | データは 100% ブラウザの `localStorage`。サーバも共有も同期もありません |
| **時間は実時間** | タブを閉じているあいだも、そのコは生きて、育って、おなかを空かせています |
| **死にます** | ただし死因は「時間」ではなく **呼ばれたのに応えなかった回数（ケアミス）** |
| **救済が 2 枚** | 夜は寝るのでコールが出ない／おでかけ中もコールが出ない |
| **代を継ぐ** | 旅立ったコは図鑑に残り、とっくんと見ための一部を次のタマゴに遺す |

## 死の設計

メーター直結で殺すと「8 時間ねただけで詰む」ゲームになります。
本家たまごっちが偉いのは、寿命が**呼び出しを無視した回数**で決まるところです。ここをそのまま採っています。

```
メーターが 25 を切る  →  コールが出る（💢 / タブのタイトルが変わる）
  応えないまま放置    →  ケアミスが増える
  ケアミス 20         →  「よわり」。コンディションが 0.55 倍。顔つきが変わる。まだ取り返せる
  ケアミス 30         →  衰弱して旅立つ
```

ケアミスが増える間隔と上限：

| 状況 | 間隔 | 1 回ぶんの上限 |
| --- | --- | --- |
| タブを開いたまま無視 | 30 分に 1 | なし |
| 留守（12 時間まで） | 3 時間に 1 | **4** |
| 留守（12 時間より長い） | 3 時間に 1 | 4 ＋ 3 時間ごとに +1（最大 14） |

ひと晩ぐっすり寝ても最大 4。そのかわり、何日も放りっぱなしにすると ちゃんと死にます。
応えた瞬間（メーターが 25 以上に戻った時点）で カウントは止まり、たまりかけもリセットされます。

**かいふく** — 4 つのメーターをぜんぶ 90 以上にすると、1 時間に 1 回だけ ケアミスを 1 返上できます。

### 終わりかたは 3 とおり

| | 条件 | 図鑑 | おくりもの |
| --- | --- | --- | --- |
| **天寿** | 168 時間 生存、ケアミス ≤ 14 | 👑 | とっくんの **1/3** |
| **ぎりぎりの七日** | 168 時間 生存、ケアミス 15〜29 | 🥀 | とっくんの **1/4** |
| **衰弱** | ケアミス 30 到達 | 💀 | とっくんの **1/5** |

七日 生きただけでは天寿とは呼びません。一度も来ないまま七日たったコは、👑 にはなりません。

## 救済 ―― 夜と、おでかけ

**夜（ローカル時刻 22:00〜7:00）はこのコも寝ています。** コールが出ないのでケアミスも増えず、メーターの減りも 1/3 になります。
プレイヤーの生活リズムに素直に乗るのが、実時間ゲームのいちばんおいしいところです。

**おでかけ** は「放置」を資源に変える仕組みです。

| コース | 時間 | げんき | おみやげ（とっくん） |
| --- | --- | --- | --- |
| 🌿 さんぽ | 30 分 | −15 | +2 |
| 🌳 もりへ | 3 時間 | −25 | +5 |
| 🏔️ とおくへ | 8 時間 | −35 | +10 |

- おでかけ中は **コールが出ません**（＝ケアミス 0）。メーターの減りも 1/3。
- そのかわり **経験値の自然増が止まります**。安全だけれど、伸びません。
- おみやげの量は **送り出したときのコンディション** に比例します。だらしなく送り出すと ろくなものを持って帰ってきません。
- 10% で「レアなおでかけ」になり、おみやげが倍になります。
- 途中で「よびもどす」こともできます（経過時間ぶんだけ受けとる）。

> 出かける前・寝る前に送り出す。そばにいるあいだは濃く世話する。このリズムがいちばん強くなります。

## アイテム

系統が ふたつ あります。**どうぐ**は 世話の手数を まとめて買いもどすもの。
**コレクション**は 強さに 1 ミリも 効かず、ただ あつまるもの。どちらも 代をまたいで 残ります
（あなたのものであって、そのコのものではないから）。

### 🎒 どうぐ ―― 13 種

| どうぐ | 効果 | 出やすさ |
| --- | --- | --- |
| 🍖 ごちそう | まんぷく +45 ／ きげん +6 | ふつう |
| 🥗 やくそうサラダ | まんぷく +22 ／ せいけつ +12 | ふつう |
| 🧶 ふわふわボール | きげん +38 ／ げんき −4 | ふつう |
| 🧴 あわあわソープ | せいけつが いっきに 100 | ふつう |
| ☕ ぽかぽかティー | げんき +36 | ふつう |
| 🛌 ゆめみまくら | げんきが いっきに 100 ／ まんぷく −8 | めずらしい |
| 🍬 けいけんの アメ | けいけんち +70（タマゴにも つかえる） | めずらしい |
| 🥤 とっくんドリンク | いちばん のばしている とっくんが +6（げんきを つかわない） | めずらしい |
| 🍀 しあわせの おまもり | つぎの おでかけの おみやげが 1.5 倍 ＋ コレクション確定 | めずらしい |
| 🔍 たからさがしレンズ | つぎの 3 回、かならず コレクションを 見つける（レアも でやすい） | レア |
| 💧 きせきの しずく | 4 つの メーターが ぜんぶ +30 | レア |
| 💊 いたわりの くすり | **ケアミス −1** | レア |
| 🕯️ いのりの ロウソク | **ケアミス −3** | でんせつ |

ケアミスを返上する 2 つだけは わざと いちばん出にくくしてあります。
ここが ゆるいと「無視した回数で死ぬ」という このゲームの背骨が 折れてしまうので。

### 🧺 コレクション ―― 500 種

10 カテゴリ（いし・はっぱ・はな・きのみ・うみ・はね・そら・おもちゃ・むかしのもの・ふしぎ）×
接頭 10 × 名詞 5 ＝ **ちょうど 500 種**。名前も 色も かたちも、id から決まります。

```
まるい こいし          ← 接頭 0（ふつう）
きらめく こいし        ← 接頭 5（めずらしい）
ひかりを のむ こいし   ← 接頭 7（レア）
でんせつの こいし      ← 接頭 9（でんせつ）
```

| ランク | 数 | 接頭辞 |
| --- | --- | --- |
| ふつう | 200 | 見たままの言葉（まるい／ざらざらの／しろい …） |
| めずらしい | 150 | すこし ふしぎな言葉（きらめく／かおる／うたう …） |
| レア | 100 | ありえない言葉（ときを とめる／ほしを はこぶ …） |
| でんせつ | 50 | 各カテゴリの 5 種だけ（オーラつきで 描かれます） |

**画像ファイルは 1 枚も使っていません。** `js/items.js` が カテゴリごとの かたち
（いしの塊・はっぱの葉脈・はなびら・かい・はね・ほし・つみき・かぎ・つぼ・ランプ…）を
その場で canvas に描き、色は id から出した色相で決めます。
「しろい」「きんの」「まっかな」など **色の名前が入った接頭辞は、その色で描かれます**。

**見つけかた**

| ところ | コレクション | どうぐ |
| --- | --- | --- |
| 🌿 さんぽ | 50% | 30% |
| 🌳 もりへ | 75% | 50% |
| 🏔️ とおくへ | 95% | 75% |
| ⚔️ やせいとの バトルに かつ | 40% | 25% |
| 🕯️ せんだいに かつ | 100% | 50% |
| おせわ（ついでに） | 5% | 3.5% |

レアに かたよる条件は **おでかけのコンディション・レアなおでかけ・相手のレベル・おまもり・レンズ**。
同じレアリティの中では、**まだ持っていないものが 少しだけ 出やすい**（2 回ひいて 新しいほうを とる）。

**20 種 あつめるごとに どうぐが 1 つ** もらえます。

## るすばん日記

タブを閉じていたあいだの出来事を、時刻つきの短文にして 帰ってきたときに見せます。
**ケアミスの請求書であると同時に、いちばん愛着がわく装置**でもあります。

```
📓 るすばん日記   9/12 23:40 〜 9/13 08:10（8時間30分の るす）
  01:20  おなかが すいて ないていた（だれも こなかった）
  03:55  まるくなって ねていた
  06:30  まどの そとの とりを ずっと みていた
  07:48  げんかんの ほうを なんども みていた
```

文体は そのコの**性格**（あまえんぼ／やんちゃ／のんびり／しっかりもの／さびしがり／くいしんぼう）で変わります。
性格はゲノムから決まるので、同じ seed なら同じ性格です。

## 図鑑と 世代継承

旅立ったコは図鑑に残ります。姿・名前・生きた時間・ケアミス・死因・称号・最終ステータス・拾ったおもいで、ぜんぶ。

- 次のタマゴは **とっくんの一部** と **見ための特徴を 1 つ**（からだの色／みみ・つの／しっぽ／めの形／もよう／つばさ／ほっぺ／たいけい）受けつぎます。
- 代を重ねるほど 面影が濃くなります。
- **3 代つづけて天寿**（👑）をまっとうすると、次のタマゴは「でんせつ」の血をひきます（種族値 +12%・金色のオーラ）。

### 🕯️ せんだいに いどむ

図鑑の記録にはゲノムの seed と血統が入っているので、**過去の自分をいつでも再現できます**。
「せんだいに いどむ」を選ぶと、図鑑から相手を選んで戦えます。

相手には**コンディション補正がかかりません** ―― いちばん元気だったころの姿で立ちはだかります。
過去の自分の育てかたが、そのまま今の壁になります。勝つと おもいでが 1 つ増えます。

## そだてかた

| ボタン | 効果 |
| --- | --- |
| 🍚 ごはん | まんぷく +28 / EXP +8 |
| 🍰 おやつ | まんぷく +12・きげん +12・せいけつ −5 / EXP +5 |
| 🎾 あそぶ | きげん +24・げんき −12・まんぷく −6 / EXP +11 |
| 🛁 おふろ | せいけつ +42 / EXP +6 |
| 💤 ねかす | げんき +46・まんぷく −8 / EXP +6 |
| ✋ なでる | きげん +8 / EXP +3（タマゴのうちからできる） |

4 つのメーターは時間で減ります（まんぷくは 8 時間、きげん 10 時間、げんき 13 時間、せいけつ 15 時間で 0 になるペース。夜とおでかけ中は 1/3）。
平均が**コンディション**（72〜100%、よわり時は ×0.55）になり、こうげき・ぼうぎょ・すばやさに直接かかります。

### とっくんと、進化の分岐

げんきを 18 使って、たいりょく／こうげき／ぼうぎょ／すばやさ のどれかを **+4**（各 120 まで）。
ポケモンの努力値のように、そのままステータス計算に乗ります。

```
さいだい HP = ⌊(種族値HP × 2 + とっくんHP) × Lv ÷ 100⌋ + Lv + 10
こうげき   = ⌊(⌊(種族値A × 2 + とっくんA) × Lv ÷ 100⌋ + 5) × コンディション⌋   （ぼうぎょ・すばやさも同じ）
```

**いちばん伸ばした値で、Lv.26 の最終進化の姿と名前が変わります**（ちからがた／まもりがた／はやさがた／たいりょくがた）。

| ステージ | 条件 | 見ため |
| --- | --- | --- |
| タマゴ | EXP < 30 | 模様つきのタマゴ。コールは出ず、死にません |
| ベビー | Lv.1〜9 | 頭が大きい小さい姿 |
| 中間 | Lv.10〜25 | ひとまわり大きく |
| 最終 | Lv.26〜 | とっくんの分岐で 4 通り |

経験値は 2 分に 1 ずつ自然に増えます（夜は 0.6 倍、おでかけ中は 0）。

## バトル

ターン制。行動順は すばやさ で決まります（遅くても 12% で先手）。

```
ダメージ = ⌊(⌊(2 × Lv ÷ 5 + 2) × いりょく × こうげき ÷ ぼうぎょ ÷ 50⌋ + 2)
           × タイプ相性 × タイプ一致(1.5) × 乱数(0.85〜1.0) × きゅうしょ(1.6)⌋
```

タイプは ほのお・みず・くさ・でんき・いわ・ひこう・あく・フェアリー の 8 種。
それぞれ 2 つの得意な相手（×2）と 2 つの苦手（×0.5）を持ち、相手が 2 タイプなら掛け算されます（最大 ×4）。

- **⚔️ たびに でる** — 野生のモンスターと戦う。げんきを 12 使います
- **🕯️ せんだいに いどむ** — 図鑑の歴代と戦う。経験値は大きめ
- **👏 はげます** — ターンを使ってこうげき +15%（最大 1.6 倍）と少し回復
- **🏃 にげる** — すばやさ差で成功率が変わります

## 時計について

完全ローカルなので、端末の時計を戻せばケアミスを消せてしまいます。
これを防ぐため、**「これまでに見たいちばん新しい時刻」より前には戻らない単調時計**（`monster.clock.v2`）を使っています。
時計を巻きもどしても、時間は止まるだけで 戻りません。

## 画像について

画像ファイルは 1 枚も使っていません。すべて `js/sprite.js` が
64×64 のグリッドに楕円やスパイクを描き、**フチどり・上のハイライト・下の影**を自動でつけて
その場で生成しています。よわっているときは まぶたと口が下がった顔になります。

## 保存されるもの

| キー | 中身 |
| --- | --- |
| `monster.pet.v2` | いま育てている 1 匹（メーター・とっくん・ケアミス・おでかけ・おもいで・ログ） |
| `monster.dex.v2` | 図鑑。旅立ったコの記録（最大 60 代） |
| `monster.clock.v2` | 単調時計のいちばん新しい時刻 |
| `monster.bag.v1` | どうぐの数・コレクションの取得状況・おまもり／レンズの残り（代をまたいで残る） |

図鑑の「ぜんぶ 消して 1 代目から やりなおす」で 全消しできます。
