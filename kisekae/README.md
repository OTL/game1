# きせかえドレッサー

女の子・男の子の人形に、顔や髪や服をえらんで着せかえるゲームです。

**▶ https://otl.github.io/game1/kisekae/**

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べます。
人形はすべて SVG でプログラムから描いているので、画像ファイルはありません。

## 遊び方

1. 上の **おんなのこ／おとこのこ** で人形をえらぶ
2. **タブ** でかえたい場所をえらぶ
3. 見本つきのボタンをタップすると、すぐ人形にうつる
4. 服・スカート（ズボン）・上着・靴は、下の **いろ** で 15 色から色をかえられる

| ボタン | はたらき |
| --- | --- |
| 🎲 おまかせ | ぜんぶランダムにする |
| ↶ もどす | ひとつ前にもどる |
| 📷 ほぞん | いまの人形を PNG 画像で保存する |
| ⟲ はじめから | さいしょのコーデにもどす |

つくったコーデは自動で保存され、次にひらいたときも残っています（女の子と男の子は別々に保存）。
